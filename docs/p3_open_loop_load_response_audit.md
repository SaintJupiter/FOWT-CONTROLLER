# P3开环载荷与响应核对

更新日期：2026年8月13日
状态：`点力映射、规定转子恒定风节点、AeroDyn轮毂载荷坐标转换及一个来源绑定的准定常转子法向载荷节点已完成；尚未建立风况到风载的运行时模型或开展跨模型精度核对`

## 目的与范围

P2已完成小角度六自由度平台骨架、三舱实际水量交接和固定参数短步推进。本阶段先不接控制器，也不围绕泵量结果调整任何策略，而是逐层核对外部作用如何进入平台方程。

首轮只核对平台坐标下的**显式作用点力**。给定力\(\boldsymbol F\)及其相对平台参考点的位置\(\boldsymbol r\)，广义载荷按

\[
\boldsymbol\tau=
\begin{bmatrix}
\boldsymbol F\\
\boldsymbol r\times\boldsymbol F
\end{bmatrix}
\]

生成，顺序为\([X,Y,Z,K,M,N]\)。这样先把力的方向、作用点和力矩参考点固定下来，尚不指定风速—推力关系，也不创建波浪激励近似。

本轮使用P2已记录的候选装配，即整机刚体质量、无限频附加质量、静水刚度、局部线性系泊刚度和重量刚度。阻尼显式取零，便于单独检查质量、恢复项和外载映射。该装配仍是控制导向的低阶候选，不替代完整OpenFAST运行模型。

## 已完成的核对

入口：

```bash
PYTHONPATH=src .venv312/bin/python3.12 \
  scripts/validation/run_fowt_open_loop_point_load_audit.py \
  --force-n 1000000 --height-m 150 --duration-s 30
```

该入口分别施加前向、左舷、后向和右舷四个水平点力。以参考点上方150 m处的\(1\ \mathrm{MN}\)力作纯映射检查时，前向力产生正纵摇力矩，左舷力产生负横摇力矩，反向载荷对应反向力矩。改变载荷方向不会改变力的大小，力矩严格按作用点叉乘生成。

对每个固定点力，脚本同时求解增量静态偏移，并将该偏移和同一载荷代回方程。六个广义加速度逐项回到数值零附近，说明在当前\(\mathbf M,\mathbf K\)装配下，点力、静态偏移和短时无控制响应使用的是同一套参考点和符号约定。静水、系泊和重量恢复项也分别计算\(-\boldsymbol q^{\mathrm T}\mathbf K\boldsymbol q\)，三项均为非正值，符合当前小扰动恢复项不向系统注入能量的要求。输出同时记录参考清单哈希、候选\(\mathbf M,\mathbf C,\mathbf K\)装配范围和逐项通过状态，便于后续恒定风与OpenFAST节点对照继续使用同一装配。

这些结果只证明**低阶方程内的载荷映射和响应关系一致**。`1 MN`和`150 m`是可读的检查输入，不是已冻结的轮毂推力或完整风机气动工况，因此不能据此报告恒定风姿态、波浪响应或物理阻尼精度。

## 规定转子恒定风节点

为检查恒定风输入后的输出通道与响应方向，增加了
`scripts/validation/run_openfast_prescribed_wind_node.py`。该入口从本地冻结的
IEA 15 MW / UMaine VolturnUS-S `v1.1.16`公开输入副本生成两个临时算例。两个
算例均启用InflowWind和AeroDyn，关闭波浪、海流和ServoDyn，固定转速为`7.55 rpm`、
三支叶片初始桨距为`1 deg`；唯一改变的输入为均匀风速。由于当前OpenFAST稳态风
输入不接受零风速，低风参考取`0.1 m/s`，不是“静止空气”工况。

采用兼容该输入版本的OpenFAST `v4.1.2`，在`0.1 m/s`和`5 m/s`之间运行`180 s`
的对照。两个算例的后半段输出均确认桨距为`1 deg`、转速为`7.55 rpm`。相对低风参考，
`5 m/s`工况的后半段均值相对低风参考出现正纵荡`4.535 m`和正纵摇`1.210 deg`。
该结果只用于确认在规定转子状态下，风速变化能够在OpenFAST输出中形成可追踪的平台
响应，并提供一个载荷转换后的方向检查节点。

这一节点不作为静态偏移或完整气动响应精度验证。后半段中纵荡仍在`6.780--12.870 m`
之间变化，说明响应尚未收敛到静态位置，不能与低阶模型的静态解直接比较。AeroDyn
输出`RtFldFxh`、`RtFldFyh`、`RtFldFzh`及相应力矩，采用随转子方位变化的轮毂坐标系`h`。
因此，脚本先在每个输出时刻读取转子方位、平台纵横摇与艏摇、机舱偏航和轴倾角，将轮毂
力及其关于轮毂的力矩转到固定参考平台坐标，再按轮毂位置移到平台参考点并统计后半段均值。
该转换仅适用于本节点的刚性运动配置，塔架变形、转子折叠、轴偏斜和Delta-3效应均关闭或为零。
输出文件头中的实际单位同时参与解析，当前节点的力和力矩单位分别为`N`与`N-m`，不依赖
固定的`kN`假设。AeroDyn输出坐标系的含义以官方说明为准：
<https://openfast.readthedocs.io/en/main/source/user/aerodyn/coordsys.html>。

在`0.1 m/s`至`5 m/s`的节点中，转换后的后半段平均广义载荷变化为
\(\Delta X=4.178\times10^5\ \mathrm{N}\)、
\(\Delta M=6.344\times10^7\ \mathrm{N\,m}\)，对应OpenFAST输出的正纵荡与正纵摇增量。
该结果核对的是载荷转换与响应方向是否可追踪，不将这组动态平均量作为低阶模型的定常风载，
更不支持“低阶模型已复现恒定风静态偏移”或“低阶气动力模型已通过OpenFAST验证”的表述。

将同一规定转子节点的风速提高至`10.74 m/s`后，这一边界更加明确。相对`0.1 m/s`低风参考，
`180 s`后半段均值的纵荡增加`16.328 m`，纵摇增加`5.274 deg`。高风组的平均纵摇为`5.075 deg`，
相对用于初始化的候选无风参考姿态`-1.452 deg`已相差约`6.53 deg`。低风组本身的后半段平均纵摇
也已偏离该候选初值，说明这两个规定转子释放算例都不能视为相应平均风下的静平衡状态。
因此，`10.74 m/s`节点仅保留为大幅平均风载下的响应量级警示和输出通道检查，不能把其后半段平均
位姿或广义载荷作为小角度增量模型的定常风载输入或对照依据，不能据此拟合恢复项或阻尼，也不能将其作为定常风载精度对照。
若后续需要该风速节点的正式对照，应先在OpenFAST侧针对明确的转子运行状态单独求取候选平衡，
再围绕该平衡释放并检查响应范围；这一步完成前，不扩展当前低阶气动模块。

为判断上述释放是否已接近可用的平均风参考，又将相同`10.74 m/s`规定转子工况延长至`600 s`。
高风算例在`450--525 s`与`525--600 s`两个末段内的纵摇均值分别为`5.091 deg`和`5.075 deg`，
但纵荡均值仍由`21.408 m`变为`21.631 m`，各段纵荡范围分别为`20.820--22.360 m`和
`21.040--22.280 m`。低风参考在相同两个时段的纵荡均值也由`5.946 m`变为`5.833 m`。
因此，这些数据只记录为末段平均响应，不生成平均风运行参考状态，也不用于低阶模型初始化。
后续若需建立该固定转子配置下的候选平衡，应先采用临时数值耗散得到候选位姿，再恢复原始
HydroDyn设置进行释放核对，并单独检查末段范围是否显著收敛。

## 临时数值松弛后的原始阻尼释放核对

为避免直接将长时规定转子算例的末段均值当作平均风平衡位姿，增加了
`scripts/validation/run_openfast_prescribed_wind_relaxation_release_audit.py`。该入口先在独立的公开
输入副本中仅附加临时数值耗散，使固定`10.74 m/s`、`1 deg`桨距、`7.55 rpm`转速、无波无流条件下的
平台状态进入缓慢变化范围；随后从该阶段末段的六自由度位姿均值出发，在另一份全新提取的公开输入
副本中恢复原始HydroDyn设置并再次释放。临时耗散只用于候选位姿定位，不解释为物理阻尼，也不用于
低阶模型阻尼标定。

在临时松弛阶段，`450--525 s`与`525--600 s`两段的纵荡和纵摇均值变化接近零，候选位姿约为
纵荡`21.620 m`、横荡`0.232 m`、垂荡`-0.524 m`、横摇`0.535 deg`、纵摇`5.072 deg`、艏摇`0.806 deg`。
恢复原始阻尼后，纵荡、垂荡、横摇和纵摇在相同两个末段之间的均值变化分别为`0.017 m`、
`-0.0002 m`、`-0.0022 deg`和`-0.0014 deg`，其中纵摇末段范围为`0.008 deg`。横荡和艏摇均值仍分别
变化`-0.097 m`和`-0.0074 deg`，表明横向与艏向仍存在残余调整过程。

因此，该运行仅记录为**固定规定转子条件下，经临时数值松弛定位并经原始阻尼释放核对的候选位姿**。
它不构成严格六自由度静平衡、正式运行参考状态或低阶平台模型的标定数据，也不用于控制器验证。两阶段
只传递位姿而未传递完整速度状态，因而不构成连续动力学轨迹的严格延续。后续先以该候选状态为起点，对
横荡和艏摇进行小幅扰动释放检查，再判断残余变化来自慢模态、残余外载还是初始状态传递。

对上述候选位姿施加`+0.1 m`横荡初始扰动后，又在原始HydroDyn设置下将扰动组与未扰动组分别释放
`600 s`。两组横荡差在`450--525 s`为`+0.03142 m`，在`525--600 s`变为`-0.01011 m`；横摇和艏摇
差也在两个末段之间跨过零值。相对差尚未形成稳定偏置，且未扰动组自身的横荡和艏摇仍分别变化
`-0.0974 m`和`-0.0074 deg`。因此，该固定风况下的横向响应在`600 s`内仍不宜视为已收束，现象与
缓慢的耦合横向调整过程一致，但不据此证明具体模态或阻尼参数。该检查同样不生成参考状态文件。

将同一审计流程用于`5 m/s`规定转子节点后，候选位姿的纵摇为`0.965 deg`，明显小于`10.74 m/s`
节点的约`5.07 deg`。恢复原始阻尼后，两个末段之间的六自由度均值变化均较小，纵荡、横荡、垂荡、
横摇、纵摇和艏摇分别变化`0.0089 m`、`0.00075 m`、`-0.00005 m`、`-0.00032 deg`、
`-0.00053 deg`和`0.00015 deg`；后一末段内纵摇和垂荡范围分别为`0.0015 deg`与`0.0006 m`。
因此，固定`5 m/s`规定转子条件下，经临时数值松弛定位并由原始HydroDyn阻尼释放复核的候选位姿，
可作为后续**恒定风载量级核对**的OpenFAST工况节点。

该节点仍不是严格静平衡、正式运行参考状态或物理阻尼验证，也不能单独证明低阶模型的整体有效性。
后续应先统一轮毂载荷到平台广义载荷的坐标与参考点口径，只比较低阶恒定风载与OpenFAST风致广义载荷
的方向和数量级，不直接比较静态位移、阻尼或完整时域响应。

在该`5 m/s`节点的`450--600 s`释放末段内，进一步将AeroDyn轮毂输出逐样本转换到候选冻结平台轴，
得到平均广义载荷约为`[8.562e5, -3.26e2, -8.876e4, -3.419e4, 1.280e8, 7.932e5]`，顺序为
`[X,Y,Z,K,M,N]`且单位依次为`N`和`N m`。以相同平均轮毂力和作用点仅计算`r×F`时，纵摇力矩为
`1.269e8 N m`，与完整广义载荷的差额约为`1.076e6 N m`，约占完整纵摇力矩的`0.84%`。这一限定
节点上，单一轮毂点力可用于纵荡力和纵摇风致力矩的量级核对。

完整艏摇力矩为`7.932e5 N m`，而同一`r×F`映射仅给出`4.744e3 N m`，差额主要来自轮毂局部力矩。
横摇中点力项和局部力矩项符号相反且量级远小于纵摇，不据此讨论横摇近似精度。后续六自由度开环分析
仍应保留由OpenFAST输出转换得到的完整广义载荷，尤其不以轮毂点力替代艏摇风载；低阶侧的首轮恒定风
载量级核对只报告纵荡和纵摇。

## 来源绑定的准定常转子法向载荷节点

为避免把`C_T`性能表、风速和轮毂作用点混为一个未说明的经验推力曲线，增加
`scripts/validation/run_rotor_normal_load_input_audit.py`。该入口只对冻结公开输入中的
二维`C_T`性能表执行一次明确的准定常换算：由公开`.fst`的空气密度、
ElastoDyn的转子半径与轴倾角，以及表内的桨距—尖速比读出共同生成转子法向力，再经
已核对的轮毂作用点映射为平台参考点处的广义载荷。

默认节点直接读取ElastoDyn给出的共同初始桨距`1 deg`和初始转速`7.55 rpm`，得到的
尖速比必须位于已发布表格范围内。命令行显式覆盖这些值时，输出会将其标为审计覆盖值，
不再将其描述为公开输入的初始运行状态。
`Wind speed vector`在该文件中仅含一个风速记录，而`C_T`矩阵没有对应的第三维数据，因此当前
实现不将其作为`C_T`查询轴。脚本要求显式给出正的对齐环境风速，但仍拒绝表外桨距或尖速比，
因而不会把二维系数表扩展成未经定义的全风速
推力曲线。固定`7.55 rpm`时，`5 m/s`输入会因尖速比超出已发布范围而被拒绝，这属于运行点
不在表内，而不是性能表缺少`5 m/s`风速层。输出记录压缩包、性能表文本、空气密度和几何输入的
来源身份，并明确标记为“外载输入审计”，不推进低阶平台状态、不接入控制器，也不与
OpenFAST平台动态状态的均值或时间响应作精度比较。

审计入口不设置环境风速默认值。后续运行时风载输入同样须明确给出环境风速与转子运行状态。

为将OpenFAST轮毂载荷与二维`C_T`表的准定常换算置于同一输入条件下，另采用`5 m/s`、`1 deg`和`5 rpm`的规定转子节点。该节点的尖速比为`12.668`，位于公开表格范围内，并得到`C_T=0.9451`、推力约`0.665 MN`及纵摇广义力矩约`98.4 MN m`。这里通过关闭发电机自由度和ServoDyn将转速运动学固定为`5 rpm`，不代表ROSCO控制器在该风速下形成的实际运行状态，也不涉及发电机扭矩或能量平衡。

在同一规定转子状态下，取`steady_wind`算例后半段的AeroDyn轮毂输出原值，而非脚本另行记录的`0.1--5 m/s`风致差值。其转换得到的纵荡力和纵摇力矩分别约为`0.644 MN`和`97.7 MN m`，与上述准定常节点相差约`2.4%`和`0.7%`。该比较仅核对对齐来流、固定参考速度条件下的载荷方向和量级，不构成`C_T`精度验证，也不比较平台位姿、阻尼或时域响应。

## 来源绑定风载的低阶链路检查

`scripts/validation/run_fowt_source_bound_rotor_chain_smoke.py`将上述规定转子节点的广义载荷仅写入低阶模型的`IncrementalLoads.wind`通道，波浪、压载和其他通道均置零。该入口保留性能表、公开输入压缩包和候选参考状态的来源哈希，并要求上游载荷审计全部通过后才继续。`5 m/s`、`1 deg`、`5 rpm`节点的平动和转动残差均接近机器精度，确认当前来源审计生成的六分量广义载荷仅进入风载通道，未与波浪、压载和其他通道叠加，并在冻结低阶矩阵下满足内部代数平衡。

这只是数据和方程接口的连通性检查。当前静态解的位移不作为平台静偏移结果，未标定阻尼也不参与响应评价；该入口不用于验证六自由度动态模型，更不进入控制器或批量工况计算。

## 后续顺序

1. 保持现有局部线性恢复项，不重新建立静水、系泊“外载模块”。它们继续按\(-\mathbf K\boldsymbol q\)核对方向和量级。
2. 在明确相对风计算、来流与转子法向关系以及不同风速/控制状态下`C_T`读出规则后，才将来源绑定的法向载荷节点扩展为低阶风载运行时模型，并用于代表性响应核对；不能把OpenFAST节点的动态均值直接硬编码为风载公式。
3. 波浪激励须在明确HydroDyn/WAMIT来源、规则波输入和低阶表示后才接入。阻尼在获得适用幅值范围内的局部等效参数前，仅检查耗散符号，不拟合六自由度物理阻尼矩阵。
4. 以上基础项完成后，才重新连接预测、候选动作、水泵和三舱状态链路，先作少量信息传递检查，不进入批量性能试验。
