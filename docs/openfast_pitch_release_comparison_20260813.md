# OpenFAST纵摇自由释放对照

日期：2026-08-13

## 目的与工况

本检查比较当前低阶矩阵模型与OpenFAST在候选参考平衡附近的小幅纵摇自由响应，只核对主周期和耦合方向，不标定阻尼或修改矩阵。

OpenFAST沿用`docs/openfast_nominal_state_release_audit_20260813.md`中的无风、无浪刚性平台配置及原始HydroDyn阻尼。初始位姿取候选参考平衡，并在纵摇方向增加`1 deg`扰动。低阶模型采用同一`1 deg`增量，质量和恢复矩阵来自`configs/reference_platforms/volturnus_s_openfast_v1_1_16.json`，阻尼暂设为零。

## 结果

| 指标 | OpenFAST | 当前低阶模型 |
| --- | ---: | ---: |
| 纵摇主周期 / s | 28.50 | 26.88 |
| 纵摇主频 / Hz | 0.03509 | 0.03721 |
| 纵荡增量范围 / m | -0.161--0.159 | -0.206--0.206 |
| 垂荡增量范围 / m | -0.0058--0.0056 | -0.000068--0.000068 |
| 纵摇增量范围 / deg | -0.978--1.000 | -1.000--1.000 |

低阶模型的纵摇周期比OpenFAST短约`5.7%`。纵摇与纵荡耦合方向一致，二者的纵荡--纵摇相关系数分别约为`0.693`和`0.705`，纵荡响应也处于同一量级。两种模型的垂荡响应均较小，但低阶模型明显低估其幅值。

OpenFAST纵摇峰值随时间衰减，而当前低阶模型尚未冻结正式阻尼，因此保持无衰减。该差异只说明下一步需要为阻尼表示选择证据来源，不能据此直接反演一组经验阻尼矩阵。

## 当前结论

当前矩阵组合能够近似复现纵摇主模态的时间尺度和纵荡耦合方向，可作为纵摇主导控制研究的第一层骨架。该结果验证的是质量与恢复刚度的组合关系，不能分别证明两组矩阵正确。垂荡耦合幅值和正式阻尼仍需单独核对。在完成这些工作前，不应宣称低阶六自由度响应已通过OpenFAST全面验证，也不应接入水泵和控制器形成新的性能结论。
