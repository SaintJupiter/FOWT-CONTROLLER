# P3 动态参考量可用性记录

更新日期：2026年8月21日
状态：`已冻结边界，尚未形成新的动态平台基准`

## 结论

冻结的IEA 15 MW/VolturnUS-S v1.1.16输入足以建立同源的**静态**质量、重心和无系泊恢复标度，但不足以在不增加建模假设的前提下，直接组装完整整机六自由度动态质量、阻尼和系泊矩阵。当前运行链路仅将这些公开字段用于静态恢复基线，未将其表述为完整同源动态模型。

## 可直接使用的量

- ElastoDyn给出平台质量、平台质心和平台自身三轴惯量。
- 塔架、叶片质量表以及机舱、轮毂和偏航轴承质量可建立整机静态质量清单与竖向质心。
- 一阶WAMIT文件给出同一平台参考点处的静水恢复矩阵与无限频附加质量矩阵。

上述量已由`source_consistent_reference.py`读取，并在无MoorDyn的OpenFAST静态纵摇端点中完成2°、5°和10°核对。该结果只支持静态恢复标度，不延伸为完整动态模型证明。

## 当前不能直接组装的量

- ElastoDyn没有给出整机各固定部件关于统一平台参考点的完整三维惯量张量。特别是机舱、转子和塔架的动态惯量不能仅由质量、局部单轴惯量或静态一阶矩无假设地合成。
- MoorDyn公开输入描述三根系泊线及其非线性时域行为，但当前尚未在一个明确的静平衡点对其求取并核对局部六自由度恢复。辅助二阶`.frc`文件中的整机刚体惯量和局部系泊矩阵仅作为显式辅助项保留，不能当作新的同源装配来源。
- 等效阻尼仍没有经过独立来源或频域响应核对，不能由静态端点反推。

## 对运行链路的影响

`BallastRuntimeAssembly`继续作为动态基准的唯一注入口。当前短步回归显式使用`static_restoring_aligned_with_aux_frc_inertia_mooring`：公开文件提供质量、重心、静水恢复和附加质量，辅助`.frc`仅提供完整惯量与局部线性系泊。该候选修正了历史混合基线的静态恢复来源，但不构成完整同源动态模型。`historical_mixed_frc_candidate`仅保留用于复现旧链路结果。

## 下一步的最小工作

下一步不是手工补齐整机惯量，也不是扩展控制性能试验，而是做一次窄范围的OpenFAST局部线性化可行性检查：在明确的静态或周期稳态工作点，检查平台纵摇、横摇相关状态和载荷是否能从`.lin`输出中被稳定识别。首轮因OpenFAST 4.1.2对卷积辐射和二阶波浪路径的线性化限制，暂时关闭波浪激励、辐射记忆和二阶差频项，仅保留静水恢复与MoorDyn作为局部状态可读性检查。OpenFAST的线性化功能会围绕指定工作点输出连续时间一阶状态空间矩阵；该能力仅作为后续局部模型核对来源，是否进入新的运行基准取决于工作点、变量定义和结果复核，不能预先视为已得到动态矩阵。[OpenFAST Linearization documentation](https://openfast.readthedocs.io/en/main/source/user/glue-code/linearization.html)

在该检查完成前，不继续向旧`core_model.py`增加系泊、附加质量或阻尼项。

## 首轮可行性结果

使用冻结的OpenFAST 4.1.2可执行文件和刚性、无风无浪节点，在60 s处成功生成一份受限配置下的全状态`.lin`文件。该配置关闭了气动、波浪激励、辐射记忆和结构柔性，只保留静水恢复与MoorDyn。文件包含894个连续状态和306个输出，前12个连续状态为平台六个位姿及其一阶导数，随后即包含MoorDyn线节点状态；输出中可直接识别`PtfmPitch`与`PtfmRoll`。线性化时刻前20 s内，纵摇范围为0.001°，相邻10 s均值差为0.000255°，可作为这一次局部状态可读性检查的候选节点。

该结果仅证明受限配置下的局部状态和平台输出可被稳定读取。由于`CalcSteady=False`且本次没有声明线性化输入，它尚未给出纵摇、横摇力矩到姿态响应的可用模型，也不能作为新的平台运行基准。后续若需要低阶动态参考，应先冻结单一工作点、完整位姿和速度残差、坐标与参考点映射，并明确通过OpenFAST声明输入或对称有限差分获得纵横摇扰动响应。完成这些条件前，不从`.lin`文件中直接摘取矩阵、推定阻尼或构造新的运行模型。

当前已经冻结的静态预载核对可作为后续工作的起点，而不是需要重复开展的试验：在同一无风、无浪、刚性配置下，HydroDyn `AddF0`施加的\(\pm10\ \mathrm{MNm}\)纵摇、横摇力矩使低阶模型与OpenFAST得到同方向的局部倾角增量，横摇、纵摇幅值分别偏小\(0.31\%\)和\(0.22\%\)。该证据只覆盖静态恢复斜率，详细口径见[OpenFAST与低阶模型的倾角一致性核对](openfast_moment_angle_consistency_audit_20260821.md)。

后续若进入动态参考阶段，只做一项新的、可判定的工作：在上述静态核对所用的同一工作点上，先明确纵摇、横摇扰动是作为OpenFAST的显式线性化输入，还是作为正负对称的有限差分预载荷施加。随后以完整平台位姿和速度的残差检查工作点是否足够稳定，并只比较该扰动下的局部响应时间尺度和方向。是否需要对894状态系统降阶、是否可形成新的低阶运行矩阵，留待这项局部动态核对通过后再决定。
