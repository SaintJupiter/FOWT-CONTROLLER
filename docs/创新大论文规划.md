## 10月3日的候选规划（保留演变过程）

以下内容整理自近期讨论、GPT Pro第19份报告及对该报告的修正。它替代文末2026年8月的下一步安排，但不改写旧版实验结论。本次只更新研究规划，未修改控制程序、训练模型或运行实验。

### 1. 背景与已有基础

研究对象为三舱半潜式浮式风机主动压载系统。三个舱分别与海水进排水，不存在舱间直接输水。水量是累积状态，水泵流量、启停和换向限制使目标不能立即实现；相同未来风况在不同姿态、舱量和泵状态下，可能需要不同动作。

小论文已投稿，旧版在150组筛选后的六小时工况中得到19.85%的累计泵量降幅。该结果属于旧模型、旧算法和旧验证条件，不是当前科研版的性能结论，也不是新方法必须达到的数值目标。

科研版已经具备可复用的研究链路：风况观测与LSTM预测、风况到广义载荷转换、平台响应、连续QP规划、目标管理、实际泵执行以及下一周期状态反馈。当前目标管理区分继续原目标、释放到实际水量和采用新MPC目标；新MPC目标来自连续优化，不能把后续工作说成首次从有限候选变为连续控制。代码入口见[控制周期](../src/wind_prediction/preview_mpc_control_cycle.py)和[连续实验](../scripts/validation/preview_mpc_continuous_experiment.py)。这些模块的存在不等于物理模型已在所有工况下验证，也不构成新的性能证据。

代码库中的[训练脚本](/Users/saintyoung/Desktop/FOWT-CONTROLLER-main/scripts/modeling/train_ballast_lstm.py)支持形状、方向和面向规划器的分块监督。但10月5日实际使用的 `lstm_segmented_fino1_meteo_aux_v1` 权重及其配置，只记录残差回归、0.02事件损失和0.02方向损失，没有记录形状或规划器分块监督；不能把脚本能力当成当前权重的训练事实。后续新方法仍须与其他已经实现且可复现的监督方式比较，而不是只选弱MSE基线。历史上面向旧死区回放的价值标签，也不能直接当作当前控制器的决策损失。

程序重构、状态一致性修复和接口统一是研究基础，不包装为论文核心创新。当前优先复用这些基础，不再为了寻找创新重新搭建控制器或实验平台。

### 2. 当前研究问题与递进关系

> 研究风况预测误差如何经过压载决策和实际水泵执行，转化为姿态与泵量差异；在发现稳定、值得改进的误差结构后，再选择相应的方法。

整体路线为：

> 已有预测辅助主动压载 -> 预测误差控制后果诊断 -> 检查普通校准和已有监督的解释能力 -> 选择一种核心方法 -> 独立工况验证与适用边界分析。

优先诊断幅值、回落或转折时刻、方向变化等误差，而不预先断言哪一种最重要。预测统计误差与控制价值不等价是已有研究的出发点，不是本课题的新发现。拟研究的具体增量在于慢泵、累积舱量、当前执行状态和有限事件持续时间如何共同改变误差后果。

DFL（Decision-Focused Learning，决策导向学习）是第一候选方法，不是已确定结论。普通校准并不需要被证明完全无效；关键是校准后是否仍存在有实际意义、值得针对性处理的损失。预测侧增量小，也不自动意味着执行协调一定值得做。

### 4. 首轮任务：受控预测误差诊断

首轮约10组不同的六小时连续工况，覆盖增强、回落、方向转折、持续振荡及低扰动。按风况特征和初始状态选择，不按哪个算法节泵更多选择。首轮用于形成假设，不据此宣布普遍性能或最终论文创新。

| 项目 | 当前执行范围 |
| --- | --- |
| 复用基础 | 复用持续性、冻结LSTM及记录未来接口和现有日志，不重建实验框架 |
| 保持不变 | 实际外部风况、控制参数、平台模型、水泵模型、初始状态及评价口径 |
| 主要扰动 | 预测幅值、回落/转折时刻、方向偏差或转向时刻；一次主要改变一种因素 |
| 扰动幅度 | 参考开发/诊断数据中的实际预测误差，正负方向均检查；不使用最终保留集选幅度 |
| 当前决策比较 | 从同一个平台、舱量、泵和目标状态出发比较未扰动与扰动预测，识别即时动作差异 |
| 连续后果比较 | 六小时内分别运行闭环，统计累积后果；后期状态分化不能归因于单次即时扰动 |
| 计算规模 | 区分工况数与对照运行次数，先估算已有入口耗时，再安排必要扰动组合，不展开全因子扫描 |

扰动以冻结预测输出为主要参照，同时记录扰动前后相对真实记录的预测误差。添加扰动有时会纠正原误差，不能把注入幅度等同于预测误差增加量。时间平移需明确边界处理，不环绕序列制造假转折；方向扰动在风矢量或圆周角度口径下处理。任何真实未来信息只可用于离线诊断及标签，不能泄露到可部署控制输入。

“动作改变比例”需同时说明目标管理类别是否变化，以及连续目标/泵请求是否超过预先选定的数值或执行分辨率。不能把浮点微差或仅类别未变当作完整动作结论。

首轮只需要三类成果：

1. 误差类型、当前动作改变比例、泵量差与姿态差的结果表，保留逐工况差异。
2. 少量能说明传递过程的时序案例，同时保留无明显影响或不利案例。
3. 对残余问题的判断：普通校准能解决什么，已有监督能解决什么，是否有必要发展新方法。

主指标包括实际累计泵量、姿态RMS/峰值与预先选定的超阈时间；控制行为另记录目标更新、暂停/释放、恢复和换向。低频姿态是补充，不替代原始姿态的峰值与超限检查。泵量不等于能耗或寿命，撤销与反向不预先判为坏动作。

末端同时记录舱量、姿态、角速度、泵状态和未完成目标。未完成目标为零不能单独证明没有把任务推迟到窗口之后，因为目标可被释放；仅在需要解释边界效应时检查相邻六小时的接续状态。统计以工况或天气事件为单位，不把每个控制步当成独立样本。

### 5. 诊断之后，如何选择一个核心方法

**预测侧候选。** 若普通校准和已有监督之后仍存在稳定、可解释的控制损失，借鉴DFL研究如何构造实际控制后果相关的训练信号。先保留风矢量输出，是否增加持续时间或转折事件输出由诊断决定。不规定必须同时改损失、输出和网络才算创新。

需要真正解决的是：评价一次动作还是连续重规划；控制差异如何形成可训练信号；是否需要表达误差符号、时间偏移和跨时刻作用；训练状态分布如何覆盖预测器改变后的实际运行。把“离线算损失再学习权重”当作候选实现，不视为这些问题已经解决。新增气象预测器不默认输出“应该释放”的动作概率；后者涉及系统状态与决策策略，是另一类任务。

同一控制器在扰动预测和记录未来下的成本之差可记为相对成本差，不保证非负，不自动具有全局最优regret的性质。若用于学习，需明确定义实际环境、共同初始状态、后续信息使用和评价时域；减去参照项本身不会解决训练梯度或代理损失设计。

**执行侧备选。** 若相同预测和实际硬件下出现可解释的目标安排不足，再从PRG或动态控制分配中选一个主要参考，替换相关决策环节，不叠加多个最终决策层。连续QP、启停约束和目标管理中已经具备的能力不重复申报为创新。

## 0. 整体概述

浮式风机在持续变化的风载作用下会产生纵摇和横摇姿态偏移，主动压载可以通过调整不同压载舱的水量改变平台质量分布，并形成相应的恢复力矩。常规姿态反馈主要依据当前倾角更新目标水量，而压载水泵的响应相对缓慢，等到姿态偏差形成后再进行调节，容易出现动作滞后和重复泵送。短时风况预测能够提供未来一段时间内的风速和风向变化，因此有可能将部分压载调整提前到风况变化的发展过程中。

现阶段已经完成短时风况预测辅助主动压载的初步研究。系统采用三个分别与海水连通的压载舱，利用历史风速和风向预测未来风况，并将预测信息与当前纵摇、横摇姿态共同用于目标水量生成。算法通过保持、减弱、常规、加强和反向等候选动作确定当前调节目标，再由受流量和舱容限制的水泵完成实际进排水，平台状态随后由六自由度模型更新。已投稿版本曾在150组经过条件筛选的6小时工况中得到19.85%的累计泵量降幅。该数值只记录旧版完整程序在特定验证条件下的结果，不代表预测方法的固定收益，也不用作科研版V2的回归基准、调参目标或验收下限。

当前工作的主要不足不在于节泵比例还不够高，而在于旧版结果中程序实现、算法作用和工况筛选的影响还没有完全分开。因此，科研版V2的结果可能低于或高于旧版19.85%，其价值应由程序完整性、姿态代价、结果稳定性和可归因性共同判断。现有150组工况主要用于保留旧版证据，尚不能代表完整连续风况中的总体收益。程序也是围绕短论文验证逐步形成的，目标保持、释放、反向修正和水泵跟踪涉及多组内部状态，后续需要统一更新时间和状态来源。三个压载舱分别与海水进排水，当前模型虽然已经更新压载质量、压载力矩和部分恢复参数，但总压载量变化对重心、惯量、吃水和静水平衡的影响仍需核查。预测、事件判断、目标保持和释放在完整算法中共同发挥作用，也需要通过分层对照进一步区分各部分的贡献。

硕士论文将在短论文基础上分两个阶段推进。第一阶段冻结短论文版本，建立科研版V2，重点统一目标和水泵状态，明确三舱独立进排水及总压载量的处理方式，使候选评价能够反映水泵有限流量和未完成目标差值，并完善算法配置、逐周期日志和自动测试。第二阶段不再单纯围绕现有候选动作调参，而是研究预测时长、水泵响应时间和风况变化持续时间之间的关系，比较姿态反馈、当前风况持续值、实际LSTM预测和真实未来信息，分析预测何时能够带来有效调节，何时作用有限或产生不利影响。在此基础上形成更清楚的预测前馈与姿态反馈协调方法，并通过未筛选的连续实测风况、不同水泵能力、不同初始压载状态以及代表性风浪组合验证其适用范围。

整个研究的递进关系可以概括为：短论文首先验证预测辅助主动压载在特定工况中的可行性，科研版V2进一步排除程序和物理关系不清带来的影响，学位论文最终解释预测信息为何有效、在什么条件下有效，以及怎样根据水泵和风况的时间尺度更合理地使用未来信息。

## 1. 当前研究基础

现有研究面向三舱半潜式浮式风机主动压载系统。三个压载舱分别与海水连通，通过各自的进排水过程改变平台质量分布，不存在舱间直接输水。当前控制目标主要为纵摇、横摇姿态调节。

短论文已经形成以下研究基础：

- 利用历史风速、风向序列预测未来短时风况；
- 将未来风况信息与当前纵摇、横摇姿态反馈共同用于压载目标生成；
- 设置保持、减弱、常规、加强和反向等候选动作，并采用滚动首动作执行方式；
- 将目标水量交由受流量和舱容限制的水泵执行；
- 根据实际舱内水量更新平台质量、压载力矩和六自由度状态；
- 建立姿态反馈、无未来预测和预测辅助等对照配置；
- 在150组经过条件筛选的6小时工况中完成900小时验证，预测辅助算法相对姿态反馈算法的累计泵量降低19.85%。

上述结果属于特定验证条件下的先导证据，能够说明短时预测参与主动压载决策具有进一步研究价值，但尚不能代表完整连续运行时段中的普遍收益。

## 4. 六项重点提升

### 4.1 控制程序与状态更新

当前程序能够完成目标保持、释放和反向修正，但这些功能分别维护部分内部状态。随着后续控制功能增加，需要统一目标状态和更新时间顺序，避免不同分支对同一变量采用不同含义。

科研版V2应固定以下周期顺序：

> 读取当前风况、姿态和舱量 -> 生成预测 -> 计算控制目标 -> 修正目标边界 -> 水泵执行 -> 更新实际舱量 -> 更新平台参数与状态 -> 进入下一周期

需要做到：

- 明确观测时刻、预测对应时刻、控制决策时刻和执行时刻；
- 区分风况数据步长、控制周期、水泵更新步长和动力学积分步长；
- 当前目标、暂停目标、恢复目标和实际跟踪目标具有唯一来源；
- 保持、释放和反向修正后同步更新相关内部状态；
- 预测缺失、拒绝或恢复时不遗留失效预测状态；
- 任一控制周期都能从日志中还原输入、动作、目标和实际执行结果。

### 4.2 三舱压载物理关系

三个压载舱分别与海水进行进排水，不采用舱间输水模型。每个舱应分别记录进水量、排水量和净变化，并进一步记录：

- 累计泵送量，即所有进排水绝对值的累计；
- 总压载净变化，即试验前后三舱总水量之差；
- 公共模态，即三舱同向变化对应的总压载变化；
- 差动模态，即主要形成纵摇、横摇压载力矩的水量变化。

现有模型已考虑总质量、压载重力、压载力矩和部分恢复刚度变化，但需要继续核查：

- 总压载变化对平台重心和转动惯量的影响；
- 净进排水对平均吃水和垂荡平衡的影响；
- 静水恢复及水动力参数是否需要随吃水变化；
- 舱容截断和三台泵异步执行是否引入非预期公共模态。

科研版V2的基础模式优先限制三舱总进排水接近平衡，使主动压载主要改变质量分布和纵横摇力矩。允许总压载量显著变化的模式作为后续扩展，不作为前期程序整理的必要条件。

### 4.3 水泵与目标水量关系

目标水量不要求在单个控制周期内完全实现，但规划过程需要反映水泵的有限响应。科研版V2至少应明确：

- 本周期各泵能够完成的实际进排水量；
- 当前目标与实际水量之间尚未完成的差值；
- 舱容、流量、启停和方向切换对执行过程的影响；
- 下一周期从实际舱量、当前目标和水泵状态继续计算；
- 候选评价是否因忽略水泵过程而反复生成与实际状态脱节的目标。

显式水泵动态是否需要进入完整预测时域，先通过小规模试验判断。若清理程序后仍广泛改变候选动作或实际结果，再将其提升为方法研究内容。若影响只发生在少量边界工况，则作为执行约束处理。

### 4.4 算法组成与差异归因

姿态反馈、持续值预测、LSTM预测和真实未来信息应尽量共用同一套控制、分配、水泵和平台模型，只替换未来信息来源或指定功能开关。

建议设置以下层次：

1. 短论文原始姿态反馈，用于复现历史结果；
2. 科研版清洁姿态反馈，用于形成工程逻辑完整的强基线；
3. 当前风况持续值，用于判断简单趋势外推的作用；
4. 实际LSTM预测，用于评价真实预测效果；
5. 真实未来风况，用于构造离线理想预览基准；
6. 短论文候选动作算法，用于保持研究连续性；
7. 简洁预测前馈与姿态反馈方法，用于检验复杂候选结构是否必要。

总体性能比较可以采用完整算法。预测、事件判断、目标保持和目标释放的独立作用，则通过分层消融逐项分析，不要求所有总体对比都只相差一个开关。

### 4.5 仿真、日志与结果分析

现有程序已经能够完成批量工况计算和部分逐周期记录。下一阶段重点是统一日志、配置和指标，而不是重新建设批量运行系统。

逐周期日志至少应包括：

- 当前风况、姿态和三舱实际水量；
- 使用的预测来源、预测时段和有效状态；
- 反馈需求、预测需求和综合调节量；
- 候选动作、淘汰原因和最终动作；
- 目标水量的更新量；
- 水泵实际流量、运行状态和未完成目标差值；
- 舱容、流量、姿态等约束触发状态；
- 公共模态与差动模态水量；
- 保持、释放、反向和反馈回退的原因。

指标应从原始日志统一生成，包括姿态响应、累计泵送量、运行时间、启停次数、方向切换、目标更新、目标与实际舱量误差、公共模态比例和预测引起的动作变化比例。

### 4.6 工况范围与验证场景

现有150组经过条件筛选的6小时工况继续保留，用于复现短论文、分析决策过程和比较新旧算法，但不再作为学位论文新方法的唯一验证数据。

验证场景分为四层：

1. **人工可解释工况**：风速阶跃、持续增强、先升后降、风向连续偏转和反转，用于检查动作方向与状态更新。
2. **实测连续风况**：从FINO1测试数据中预先冻结连续时段，不根据最终泵量或姿态筛选，由控制器在线决定是否使用预测。
3. **系统状态变化**：改变初始舱量、舱容余量、初始姿态、水泵流量和控制步长，研究算法对系统状态和执行能力的敏感性。
4. **环境复杂度扩展**：在代表性工况中加入不规则波和不同风浪方向，检查结论在更复杂环境下是否保持。

停机、预测中断、泵能力下降和极端海况可作为增强验证，不在第一阶段全部展开。

## 5. 科研版V2的验收标准

达到以下条件后，程序整理阶段停止，进入学位论文的科学问题研究：

- 短论文V1代码、配置、数据、模型和冻结的150组证据包能够独立核查。确需重新计算时拆分为单批不超过30组的6小时实验；
- V2不存在已知的关键目标或状态同步错误；
- 三舱进排水、总压载量和压载力矩关系明确；
- 四种未来信息来源能够通过统一接口切换；
- 各算法共享相同的水泵、舱容、平台模型和评价模块；
- 任一控制周期的输入、动作、目标和实际泵量均可追溯；
- 水泵、舱容、质量更新和目标生命周期通过核心测试；
- 人工工况符合预期物理响应；
- 连续6小时运行稳定，不出现隐藏重置或异常回退；
- 相同输入和配置能够重复生成一致结果；
- 关键指标能够由原始日志自动生成；
- 批量试验能够保存代码、模型、数据、工况和配置身份。

V2的完成度以支持可信研究为准，不要求达到实时硬件、故障诊断、认证或工业部署标准。

## 6. 学位论文的候选研究主线

### 6.1 工作题目

> 面向多时间尺度协调的浮式风机预测辅助主动压载调节方法

题目为暂定表述，待V2和前期试验完成后再确定是否强调预测误差、泵送动态或海水交换式三舱结构。

### 6.2 核心科学问题

> 当预测时长、水泵响应时间和风况变化时间处于不同关系时，未来风况信息应如何参与当前压载调节，才能在控制姿态响应的同时减少无效进排水？

短论文回答了预测信息在部分条件工况中能否产生作用。学位论文进一步回答：

1. 真实未来信息相对姿态反馈是否具有稳定价值；
2. 实际LSTM能够实现多少理想预览收益；
3. 预测收益来自提前加强、提前减弱、目标保持还是避免反复进排水；
4. 预测时长、水泵响应时间和风况变化持续时间如何共同影响结果；
5. 预测在哪些条件下有效、无明显作用或产生不利影响；
6. 简洁前馈与反馈方法能否解释主要机制，现有候选动作是否仍有必要。

### 6.3 潜在方法贡献

以下为候选贡献，需要通过前期试验确认，不预先写成既定创新点：

1. 建立三舱独立海水进排水的控制导向模型，并区分总压载公共模态与纵横摇差动模态。
2. 根据水泵响应时间、预测时距和风况持续时间确定未来信息对当前调节的作用程度，形成多时间尺度协调的预测前馈与姿态反馈方法。
3. 建立从条件工况到完整连续时段的验证体系，给出预测辅助主动压载的适用范围及失效条件。

普通三舱约束分配、程序缺陷修复和增加仿真数量本身不作为主要创新。

## 7. 前期必须完成的比较与试验

### 7.1 四种信息层级

在相同控制、泵和平台条件下比较：

| 信息层级 | 作用 |
| --- | --- |
| 姿态反馈 | 无未来信息基准 |
| 当前风况持续值 | 判断简单外推能否获得相近收益 |
| 实际LSTM预测 | 评价真实预测信息的控制价值 |
| 真实未来风况 | 构造离线理想预览基准，不称为物理理论上限 |

### 7.2 水泵能力与预测时长扫描

改变水泵流量、预测时长和风况变化速度，分析三个时间尺度：

- 典型压载调整所需时间；
- 风况增强、回落或转向的持续时间；
- 有效预测时长。

重点判断：

- 水泵很快时，姿态反馈是否已经足够；
- 水泵响应与风况变化处于同一量级时，预测是否最有价值；
- 水泵响应远慢于有效预测时长时，未来信息是否难以转化为实际动作；
- 增加预测时长是否因远时段误差而产生收益下降。

### 7.3 候选动作与简洁方法比较

保留现有五类候选动作作为冻结算法，同时建立一个物理含义清楚的简洁方法：

> 未来风况 -> 未来平均风倾覆力矩 -> 预测前馈与姿态反馈融合 -> 三舱目标分配 -> 水泵执行

若简洁方法能够达到相近或更好的效果，学位论文可以重构现有候选动作。若候选动作在姿态、泵量或稳定性方面仍具有明显优势，则保留并进一步形式化其作用。

## 8. 阶段安排

### 阶段A：证据冻结与现状审计，约1周

- 冻结短论文V1代码、配置、数据、模型和结果；
- 补充代码、模型和数据校验值；
- 汇总已确认问题与待核验假设；
- 明确三舱进排水方向、流量及总量约束。

### 阶段B：状态与物理关系加固，约1至2周

- 统一目标生命周期和控制周期更新顺序；
- 审计总压载量、公共模态和差动模态；
- 补充水泵、舱容、质量及目标状态测试；
- 明确V2基础模式中的总压载约束。

### 阶段C：统一基线和实验接口，约1至2周

- 建立科研版清洁姿态反馈；
- 统一持续值、LSTM和真实未来输入；
- 统一日志、指标和运行配置；
- 完成人工可解释工况和连续6小时检查。

### 阶段D：前期研究判定，约4至6周

- 开展四种信息层级比较；
- 扫描水泵能力和预测时长；
- 比较候选动作与简洁方法；
- 在未筛选连续时段检查净收益；
- 根据结果冻结最终课题主线。

### 阶段E：学位论文主体研究与扩展验证

- 形成正式控制方法；
- 开展实测连续工况和参数敏感性分析；
- 加入代表性风浪组合；
- 视资源情况开展OpenFAST或其他耦合模型验证；
- 完成消融、统计分析和适用边界讨论。

## 9. 研究路线判定条件

### 9.1 继续预测辅助主线

满足以下大部分条件时，继续研究多时间尺度协调：

- V2修复后，实际LSTM相对清洁姿态反馈仍具有稳定优势；
- 真实未来信息明显优于持续值和姿态反馈；
- 实际LSTM能够实现一定比例的理想预览收益；
- 预测收益随水泵能力和风况变化时间呈现可解释规律；
- 收益不只存在于150组条件工况；
- 姿态代价处于预先设定的允许范围内。

### 9.2 转向决策相关预测研究

若真实未来具有明显优势，但实际LSTM只能实现很小一部分，则将重点转为：

> 短时风况预测误差对主动压载动作选择的影响及选择性预测辅助调节

主要分析错误加强、错误保持、错误释放和预测拒绝，不继续扩展复杂水泵规划器。

### 9.3 转向三舱压载分配研究

若真实未来相对姿态反馈也缺乏稳定优势，或预测收益只来自特定死区、程序分支和少量筛选片段，则不再强行以预测为核心，转向：

> 海水交换式三舱主动压载的姿态力矩分配、总压载模态管理与耦合响应研究

主要研究公共模态、纵摇模态和横摇模态分配，以及净进排水对质量、吃水、姿态和载荷的影响。

## 10. 当前不纳入主线的内容

现阶段不将以下内容作为课题成败的前置条件：

- 复杂概率风险、CVaR或机会约束；
- 完整混合整数MPC；
- 强化学习控制器；
- 全面的水泵故障诊断与容错控制；
- 风机桨距、转矩与主动压载的联合优化；
- 工业实时通信、图形界面和硬件在环；
- 完整OpenFAST动态压载接口；
- 缺少扬程、效率和管路参数时的泵能耗及寿命结论；
- 仅为保持19.85%而保留不合理程序逻辑。

## 11. 向导师汇报的简要表述

> 小论文在150组设定工况中显示，短时预测参与主动压载决策具有降低累计泵量的潜力。下一阶段首先对现有程序进行系统整理，统一目标水量及内部状态的更新过程，明确三个压载舱独立进排水和总压载量变化的处理方式，并在候选评价中反映水泵有限流量及未完成目标差值。同时，将预测输入、事件判断、目标保持和释放分别设置为可独立比较的环节，完善逐周期决策记录与参数扫描。在此基础上，进一步研究预测时长、水泵响应时间和风况变化速度对主动压载效果的影响，并通过连续实测风况和不同系统状态明确算法的适用范围。

最核心的提升可以概括为：

> 从目前能够得到完整算法的总体结果，提升到能够分辨预测信息、动作选择和水泵响应分别如何影响最终调节效果。
