## 4. 阶段A必须落实的关键接口

### 4.1 绝对目标、规划流量和实际达到状态

保留源码质量单位。令`r`为三舱绝对目标质量，`m`为实际/预测达到质量，`q`为体积流量。两模态目标可写为：

\[
r_{g,j}=r_{\rm anchor}+Da_{g,j},\qquad \mathbf 1^TD=0.
\]

`r_anchor`、公共目标总量、`D`的单位和参考状态必须在A中从现有映射落实。一个问题内的共享目标使用共同物理参考；尾段可代数换基准，但不能让不同情景偷偷改变公共目标总量或绝对目标。实际异步泵送造成的暂态总质量差异保留，不投影成理想零净变化。

**共享绝对目标不等于共享实际流量，也不等于共享实际舱量增量。**相同目标下，不同达到状态可以通过相同底层跟踪规律产生不同流量。这是允许的状态反馈，不是允许同组情景偷偷选择不同目标。

三层量分别保留：

| 层次 | 输入和输出 | 用途 |
| --- | --- | --- |
| 规划近似 | 目标、预测达到质量、必要执行状态 → `q_plan`与下一预测质量 | 联合优化的状态传播和尾段成本 |
| 首块预演 | 候选请求、真实根状态副本、预测环境 → `q_exec`与达到状态 | 判断候选首块执行后果，重建尾段 |
| 实际回放 | 最终请求、实际状态、记录环境 → `q_actual`与真实下一状态 | 唯一真实推进及最终指标 |

三者均遵守质量平衡；规划中至少要写清：

\[
m_{l+1}^{s}=m_l^{s}+\rho\Delta t_lq_{{\rm plan},l}^{s},
\qquad e_{r,l}^{s}=r_{n(l,s)}-m_l^{s}.
\]

**只有质量平衡还不够，必须另外给出`q_plan`如何由目标误差与执行状态决定或受限。**不能让流量成为与目标无关的第二套自由控制，更不能默认为`m_{j+1}=r_j`，将未完成目标直接消去。

A的完成产物必须说明：

1. 选用的具体映射及对应函数，哪些量冻结、哪些量随决策变化，系数来自哪一已有参数或近似。
2. 当前流量、剩余目标、限流/爬升以及保持/释放在该映射中的处理；哪些锁存、驻留或换向只留在首块真实模型。
3. 哪些规划状态确实需要补充；若需要三舱质量或流量状态，这只是状态表达，不增加第三个压载决策自由度。
4. 实际达到质量、滤波和必要泵状态如何初始化尾段，不能仅传理想模态终点。
5. 近似有效范围与越出范围时的处理，同一份映射如何用于所有配置。

优先从现有块模型、执行能力包络和目标跟踪规律形成最少改动的映射。可以选择有明确适用范围的局部仿射近似，但这仍待A落实，不在本文凭空指定泵增益。若模式冻结，应记录冻结依据；两阶段求解中不得更换近似、分组或约束。跨模式误差不能通过反复重线性化或扩大范围来追求M3获胜。

现有“请求模态增量在一块内线性完成”可以保留为历史参照或明确标记的理想化近似，不能换名后称为完整目标跟踪模型。若暂时只能支持该近似，报告其限制，先做独立接口工作，不声称已完成执行一致的研究控制器；也不立即升级为全混合整数优化。

### 4.2 状态所有权和块内滤波

真实推进器持有`平台状态、实际质量、泵状态、有效目标、滤波历史`。候选和情景从该根状态的只读事实/副本出发，复用现有不可变执行状态，不创造并行的“真状态”。

若采用因果一阶滤波，示例离散定义为：

\[
\zeta_{l+1}=a_l\zeta_l+(1-a_l)\theta_{l+1},\qquad
a_l=\exp(-\Delta t_l/T_f).
\]

采用哪种滤波需结合已有低频定义确定；若模型状态已经代表所需低频量，先说明对应关系，不机械重复滤波。上式只是可选离散定义，不是对连续姿态的精确积分证明。

平台积分网格、规划检查网格、滤波网格和600 s控制网格分别记录。FINO1区间均值按其真正可获得时间使用；下一观测分组用的量必须在下一决策前已经可得。原始姿态运行限制和模型范围不会被低频任务带替代，历史5°不自动成为任务带。

## 6. 目标函数、联合尾段与最终接受

### 6.1 分层目标

M0/M1保留第3节已核查的加权语义，运行与终端项一并对齐。M2/M3沿主规划采用线性区域松弛，先最小化低频任务偏离`J_task`，再最小化预计累计体积泵量`J_volume`：

\[
J_{\rm task}=\sum_s p_s\sum_{l,a}\frac{\Delta t_l}{T_{\rm ref}}
\max\left(0,\frac{|\widetilde\theta_{l,a}^{s}|-b_a}{s_a}\right)
+J_{\rm terminal,task},\qquad
J_{\rm volume}=\sum_s p_s\sum_{i,l}|q_{{\rm plan},i,l}^{s}|\Delta t_l.
\]

参考姿态、任务带`b`、轴尺度`s`、时间尺度和终端权重固定说明。两阶段使用同一状态、情景、执行近似及约束，第二阶段要求：

\[
J_{\rm task}\le J_{\rm task}^{*}+\epsilon_{\rm task}+\epsilon_{\rm num}.
\]

严格任务优先以`epsilon_task=0`为起点，数值容差不能充当隐性任务退让。用线性松弛实现区间外绝对偏离与绝对泵量；第一阶段未收紧的泵量辅助变量不能作为真实成本，返回后按流量重新计算。

区域终端只计约定的任务带外偏离，不暗中恢复追零；首轮不新增复杂终端集合或强制共同水量终态。加权终端和区域终端可以不同，差异计入目标组织因素。运行积分、首块/尾段接点和终端项分别定义，避免无意重复；明确的终端代价不等于重复计数。

线性构造可形成LP/QP，但二次任务上界是二次约束，精确混合泵也不再是普通QP。求解形式服从真实设计，不为保留OSQP而错误宣称线性。有限采样和有限情景的约束不自动具有连续时间、真实分布或递归可行性保证。

### 6.2 首块后必须联合重算尾段

沿用继续有效目标、释放目标、新优化目标三种候选。不增加人为强弱档位。保持目标可能继续泵送；释放不瞬间停泵，也不撤回已经发生的水量。

每个候选从相同真实根状态出发，用各预测情景作环境，执行首块预演。保存达到的平台、质量、泵、目标和滤波状态，再以这些状态重建尾段。**同组共享未来绝对目标的约束必须保留；不能逐叶独立最优后相加。**

若当前泵模型不直接依赖风，同一候选的泵/质量首块可以复用确定性预演结果，平台与滤波仍按情景传播；先确认接口依赖，不为情景数机械复制计算，也不提前开展求解加速研究。

加权配置按相同全时域加权公式复评。区域配置采用有限候选集合上的两遍计算：

1. 对每个物理可接受候选`a`，求`T_a_min = T_prefix(a) + min(T_tail(a))`；尾段包括相应终端任务。
2. 取`T_best = min_a T_a_min`，形成**一个共同预算**`B_task = T_best + epsilon_task + epsilon_num_accept`。
3. 对任务可达到该预算的候选，在`T_prefix + T_tail <= B_task`下求整段最少泵量，比较`V_prefix + V_tail`。

任务退让只加一次，不能尾段加一次、候选排序再加一次。原根优化值、候选最佳任务值和最终接受值分开记录。这仅是给定候选集合与尾段近似模型下的分层选择，不是实际系统全局最优。

近似并列时复用现有实际泵量、运行时间、启停及稳定标识排序，并写明是首块还是全时域量。不默认保留旧目标更优，不默认增设第三级优化。只有内部多解确实引起执行不稳定时，才定向处理。

`N=1`按空尾段处理，终端只按定义计入。首块或尾段不可接受的候选不能删除尾段成本后参与正常竞争。两阶段失败、候选拒绝、模型范围退出、运行回退分别标记；不得静默删情景、放宽边界或读取真实未来。现有回退可维持程序运行，不因此称为已认证安全。

## 8. 检查与日志只围绕新增机制

首轮复用既有执行、单位、时间合同和M0测试，**新增检查仅针对新增滤波/映射接口**。C之后再随对应机制补检查，不把完整指南的所有测试提前塞进A/B。

| 检查时机 | 重点性质 |
| --- | --- |
| A/B | 根状态不被预演修改；实际与预测滤波同定义且继承历史；块内样本不漏算/重算；M0行为变化来源明确 |
| C | 区域内罚为零但仍可提前行动；第二阶段任务值符合声明容差；跨候选不重复退让；实际往返泵量不是净量 |
| D/E | 观测相同但续段不同仍共享目标；绝对目标与质量基准一致；单情景及重复样本分摊权重的退化一致 |
| E/F | 尾段从达到状态开始且仍联合；预测/实际通道隔离；`N=1`；失败分类、终端和计时不重复 |

有多解时先比较目标值、可行性及共享约束，不要求每个优化变量逐点一致。正确性测试不使用“必须比旧控制器节泵”作为断言。直接修改未发生的真实未来而观察当前决策是否变化，只能用于因果隔离检查，不作为正式性能案例。

沿用原日志，仅补足情景来源/分组、M0身份、执行近似版本、滤波/任务定义、名义与情景平均载荷、求解/首块/尾段分量、统一预算及接受理由。完整问题矩阵只在失败或需要复现时保存，不建设新遥测系统。

最终结果使用`sum_i integral(abs(q_actual_i))`，另报进水、排水、净量和末端剩余目标；区分三泵累计设备运行时长与任一泵运行的系统时长。原始双轴姿态、低频任务偏离、模型范围事件和截短结果共同报告。任务达标不等于姿态表现完全相同，实际泵量不直接等于耗电或寿命。
