# 两篇近期预测控制论文全文精读与主动压载迁移评估

日期：2026-10-06。材料：用户经学校数据库取得的两篇出版版PDF。本轮只阅读论文、核对当前代码和更新研究笔记；没有修改控制器、训练预测器、调参或运行控制实验。

## 1. 先给结论

两篇论文都提供了可落实到公式与算法的借鉴对象，而不只是一般思路。但它们解决的不是同一个问题，不应直接拼成一套声称具有两者全部保证的新算法。

- **Hoang等2025**最适合做近期的“概率预测接入多阶段控制”参考。其具体实现是预测均值/标准差、少量代表场景、加权代价和分支约束。它没有给出适用于本项目的完整概率保证、执行保证或原创压载机制。
- **Gostin与Koeln 2024**提供更明确的时间误差集合、约束收紧和终端集合构造。它有具体定理，但适用假设更窄，不能直接移植到不断重预测、存在混合泵状态的压载闭环。
- 当前代码已有确定性多步优化、首周期真实执行预演、候选尾段重优化和实际状态反馈。不能把后续工作说成“首次考虑未来”“首次考虑泵状态”或“首次滚动修正”。
- 当前尚未形成经过论证的原创控制机制。合理的研究顺序仍是：明确现有数学基准 -> 构造够用的标准母体参照 -> 写清一个对象特定修改 -> 分析与该修改相对应的性质 -> 统一验证。无需先靠几个窗口证明旧方法普遍很差，也不能从理论合理直接跳到收益已成立。

全文使借鉴更具体，同时也暴露出必须保留的限制。近年发表并不意味着无经验参数、无近似假设，也不意味着照搬后自然超过现有控制器。

## 3. H：到底提出了什么

### 3.1 原文的核心构造

对象是燃气机组、风电和电池组成的孤立能源系统。要求满足功率需求，并降低燃气机组的温室气体排放。电池SOC是累积状态，具有容量约束；这与压载水量存在结构对应，但不是完整物理等价。

| 构造 | 位置 | 内容与边界 |
| --- | --- | --- |
| 原随机优化问题 | p.282，式(4) | 期望代价与供需误差的概率约束。这是理想问题描述，不是后续有限场景近似已精确求解该问题的证明。 |
| 随机灰箱预测 | pp.282-283，式(5)-(7) | 用历史数据拟合SDE，以当前观测与气象预测驱动，得到未来均值和不确定性；Lamperti变换用于改善分布表达/计算。并非LSTM，也不是必须替换本项目LSTM的理由。 |
| 多阶段近似 | p.283，式(8)-(12) | 以节点/场景权重累计代价，在代表分支施加动力学和约束，当前共同动作满足非预见约束。 |
| 代表扰动 | p.283，式(9)、(13)-(15) | 用均值及正负标准差倍数表示名义、较高、较低扰动。分支不是从任意联合路径分布精确积分得到的。 |
| 在线流程 | p.284，Algorithm 1 | 新观测和新气象预报 -> 更新概率预测 -> 解多阶段优化 -> 执行首动作 -> 下一轮更新。 |

为便于比较，其扰动近似可概括为：

\[
d_j^i\approx\mu_j+\delta_j^i,\qquad
\delta_j^i\in\{-\beta\sigma_j,0,+\beta\sigma_j\}.
\]

这是对式(9)、(13)-(14)的简化转述，不取代原文的树索引。文中确实给出

\[
\beta=\sqrt{(1-\epsilon)/\epsilon}
\]

作为基于不等式的保守联系，同时明确允许试选更不保守的系数。不能因此说任意非线性系统用三个分支就具有整段轨迹的违约概率保证。

### 3.2 比此前摘要判断更具体的四个限制

**实际算例只用一个分叉阶段。** p.285明确设置稳健时域 `N_R=1`、`beta=1`，每150秒重算、向前看5小时。p.283的图2画的是 `N_R=2`，不能把示意图当成实际算例配置。式(10)写了首动作相同；对于其短稳健时域近似，这不是自动错误，但也不等于已经处理本项目中任何时刻、任何部分观测下的信息逐步揭示。

**场景近似不等于已校准的联合概率模型。** 式(8)保留场景权重，式(11)-(12)使用近似符号。这7页正文没有提供可直接用于本项目的节点概率估计、跨时刻联合校准和闭环联合违约证明。将来若做多阶段压载，不能随意给“高/中/低”各三分之一概率后宣称概率控制成立。

**分支宽度仍有选择空间。** 原文允许通过试选或概率不等式选择 `beta`，算例取1；不能称它消除了调参。预测统计参数、风险要求、控制偏好权重和求解器数值设置需要分开，不能全靠同一批控制结果挑选。

**原文验证不是物理系统实测闭环。** p.284假设仿真对象与控制模型一致、全状态反馈、无过程/测量噪声；不确定性来自风电预测。真实历史数据用于驱动仿真。p.285只选了验证年份中的两个日期展示控制结果，没有报告整年闭环统计，也没有新增完整闭环稳定性/递归可行性定理。

### 3.3 原文收益是什么

p.285，Table I：`e`是累计功率需求误差，单位MWh；`GHG_gtg`是相对完美预测基准的排放增幅，不是相对前一行的降幅。

| 算例 | 方法 | 需求误差/MWh | 相对基准排放增幅/% |
| --- | --- | ---: | ---: |
| 第1天 | 原气象预测的确定性NMPC | 0.00 | 0.31 |
| 第1天 | 概率预测均值的确定性NMPC | 0.00 | 0.50 |
| 第1天 | 概率预测+多阶段NMPC | 0.00 | 0.26 |
| 第79天 | 原气象预测的确定性NMPC | 38.46 | 1.76 |
| 第79天 | 概率预测均值的确定性NMPC | 13.47 | 1.86 |
| 第79天 | 概率预测+多阶段NMPC | 0.00 | 0.30 |

两个算例的完美预测基准均为0.00/0.00。p.285为可比性令各控制器仿真结束时电池SOC为0.1；压载应用不能照搬这个数值或不加判断地强制末舱量相同。

值得借鉴的是实验分解：**保持预测均值不变，再比较是否使用不确定性**，从而区分“预测改得更准”和“控制器更会利用预测”。这些数据支持两例中的效果，不证明跨系统普适收益。即使使用记录未来，也只是该控制器的诊断参照，不自动是全局性能上界。

p.286，Table II：多阶段整轮平均计算时间为0.69/1.35秒，周期为150秒。它说明该实例算得动，不支持本项目必须优先研究场景压缩；也不能把平均耗时当成最坏时延保证。

### 3.4 对“师兄路线”的意义

该文p.281直接说明其贡献是将既有SDE概率预测和多阶段控制结合成完整框架。它是有效的近期方法参照，但不是一篇可直接替我们提供“新的压载控制律”的论文。

可以借：概率信息的明确身份、短稳健时域参照、分支优化、同均值对照。不能直接借来当原创：SDE、三分支、非预见约束、SOC式累积状态、滚动执行。

若把它直接改成“LSTM+三种未来风况+三舱控制”，主要成果仍是算法迁移。要达到用户所要求的对象特定方法深度，仍需明确改变哪一步策略构造，并说明这个变化为何改善压载任务。

## 4. G：时间不确定预览方法

### 4.1 真正的对象与不确定性

pp.2489-2490，式(1)、Assumptions 1-3：精确离散LTI系统、有限任务 `k=0,...,N`、给定直到任务终点的名义扰动轨迹。实际扰动满足

\[
x_{k+1}=Ax_k+Bu_k+d_k,\qquad
d_k\in\{\hat d_{k+s}:s\in[\underline s,\overline s]\cap\mathbb Z\}\oplus\mathcal W.
\]

`W`是包含原点的紧集，描述幅值误差。这里的时间偏移可以逐时刻不同，**不只是整条曲线采用同一个固定时延**。但它仍围绕给定轨迹定义，不包含LSTM在下一轮任意重写整段名义预测的规则。

p.2490，式(3)：先将窗口样本的离散选择放松为凸包，再加幅值误差，减去当前名义值，得到

\[
\widehat{\mathcal D}_k
=\operatorname{conv}\{\hat d_{k+s}\}_s
\oplus\mathcal W\oplus\{-\hat d_k\}.
\]

III-B还允许不同扰动分量使用不同时间窗口、独立移位。它已经覆盖了“不同分量在不同时间发生”的一种具体构造，不能把该构造换成风矢量就声称原创。独立分量放松也可能引入真实路径中不会出现的组合；是否保留物理相关性要另行判断。

### 4.2 不是风险打分，而是可计算的误差传播与收紧

p.2489，III-A采用反馈 `u=hat u+Ke`，要求 `A+BK`稳定，误差集递推为

\[
\mathcal E_{j+1|k}=(A+BK)\mathcal E_{j|k}\oplus\widehat{\mathcal D}_j,
\qquad \mathcal E_{k|k}=\{0\}.
\]

p.2490，式(4d-e)、(6d-e)要求名义状态与输入落在

\[
\hat x_{j|k}\in\mathcal X\ominus\mathcal E_{j|k},\qquad
\hat u_{j|k}\in\mathcal U\ominus K\mathcal E_{j|k}.
\]

含义是先给扰动引起的偏差留出范围，再优化名义动作。原文优化的是名义二次代价，不是最坏情形代价，也不是用概率给物理载荷打折。

两种控制器的差别如下：

| 版本 | 终端与未来信息 | 原文结论 |
| --- | --- | --- |
| 缩短时域，式(4) | 每次一直规划到固定任务终点N，终端状态进入收紧后的任务终端集 | Theorem 1在初始问题可行及规定假设下宣称有限任务递归可行、状态/输入/终端约束满足 |
| 短时域，式(5)-(8) | 从任务终点反向构造wayset，编码预测范围之外剩余任务的鲁棒可达性；按候选延续是否可行维持或缩短在线时域 | Theorem 2的保证依赖wayset、跨周期误差集合关系与时域更新规则，不是任意固定短时域控制器的保证 |

wayset可以理解为“从这个时刻的哪些状态出发，仍能在后续扰动下完成剩余任务”。它不是一般的无限时域不变终端集。论文短时域算例初始5步，但可能逐步缩短到1步；不能只看“5步”就认为它等于本项目固定六步持续重规划。

两项证明是援引已有工作的论证概要，不是对任意新模型的自动担保。全文没有证明任意预测重写、无限持续任务、混合泵执行下的可行性，也没有以这些定理证明累计泵量更少。

### 4.3 对照本项目，哪些前提不匹配

1. **预测更新。** 原文同一绝对时间有给定名义值 `hat d(j)`；本项目是 `hat d(j|k)`，新观测到来后整段预测可能改变。相同宽度不保证新旧集合嵌套。集合嵌套也不是唯一可能的证明路线，但跨更新的误差关系和可行延续必须说明，不能只重新算一次QP就继承原定理。
2. **短预览与任务长度。** 本项目通常只有未来60分钟信息，长期持续运行；原文短时域背后仍有直至任务结束的轨迹和wayset。时间窗口向前延伸还可能需要预览范围外的信息。论文算例中的端点常值延拓只是其边界处理，不能自动视为真实未来风载的可靠范围。
3. **泵执行。** 目标指令经实际执行层后才形成水量，启停/驻留/爬升和舱容限制不等于 `u=hat u+Ke` 与静态输入集合。把泵放在优化之后裁剪，可能改变原误差传播；必须描述规划输入、实际执行和误差界之间的关系。
4. **载荷与状态增量。** 文中 `d`直接加到状态转移。本项目风矢量先经转子载荷转换，再通过离散模型映射到状态，不能将风速误差直接放到姿态状态误差集。不同方向的高风速也不统一等于最坏横摇/纵摇。
5. **矩阵随压载状态变化。** 本项目一轮内冻结平台矩阵，下一轮按实际状态更新；原文证明针对固定LTI模型。若保留这种更新，需要补充调度/模型偏差的处理，不能以“每一步都是线性的”替代跨周期证明。

这些是迁移条件差异，不是已证明未被其他文献解决的原创缺口，更不是当前程序必然表现很差的证据。

### 4.4 算例和公式检查

pp.2492-2493：二维状态、单输入的双积分器，任务40步；状态/输入限于正负1，幅值扰动为正负0.05，两分量时间窗口分别为[-1,3]、[-3,1]；终端集取状态约束集，并不要求回零。图3、图4分别展示1000条扰动轨迹，支持所述算例内的约束保持。

图5比较100次运行的整段在线计算时间，说明短时域方法在较长任务上扩展更好，短任务不一定更快；未给出完整离线代价比较。本笔记不把图上读数当精确表格。原文没有确定性基准下的压载泵量、姿态或实际节能对照。

pp.2491-2492作者明确承认：误差外包络会增加收紧，wayset内近似可能人为变空；把终端集合进一步变成分量独立边界尤其可能制造不可行性。这是不能机械地以“更保守”代替“更好控制”的直接提醒。

**实现前需要校正的排印/推导问题。** 独立审查指出、主对话已对出版版图像核对：式(4b)、(6b)写 `hat d(k)`，而III-A的名义动力学写 `hat d(j)`；式(4f)将向量写成等于集合；式(8)保持和缩短两个分支都印为候选集合为空，与前文“非空才可延续”矛盾。按上下文应分别核对时刻索引、集合归属和非空条件，不直接逐字抄入代码。

式(7)的终端延续输入集合还疑缺名义扰动平移项，这是审查者根据名义动力学提出的待核推断，不作为已证伪整篇论文的结论。本轮不扩展成作者代码审计；真正复现时从状态方程独立推导即可。上述问题不抹去其方法价值，但说明“已有论文有公式”不能替代本项目的推导核对。

\[

\]

其中 `zeta` 是14维预览状态，`Delta a` 是2维压载模态增量，`tau`是6维广义载荷。实际链路仍为

\[

## 6. 不拼凑的迁移安排

### 6.1 保留一个主参照，而不是并排叠加决策层

若维持“提前动作与以后条件修正”的研究目标，H的小规模多阶段框架更直接；经典多阶段文献负责理论溯源。无需为了复现H同时重训SDE、换掉LSTM或改成全非线性平台，保留现有线性模型能隔离控制方法变化。

用户随后提供的GPT Pro意见建议优先采用G，先研究时间偏差下的规划约束。这是合理的**候选草案选择**，但不是全文事实自动推出的唯一主线：G主要解决规定误差类内的约束保证，不直接联合设计不同未来信息节点下的动作。两者不能作为先后叠加的监督层，也不能只凭两篇论文就认定时间误差是本项目最重要的误差。

下一份草案可以先按G写有限时域的误差传播与可执行条件，暂不同时实现H；保留H的对照拆分方式及条件决策参照。该选择只是收窄一次纸面任务，不等于正式锁定核心创新或承诺鲁棒方法会改善姿态—泵量关系。若后续继续声称“考虑未来信息更新后的条件动作”，则必须补上相应的信息结构，不能仅凭G的误差集传播声称已经做到。

### 6.2 下一份方法草案应写清什么

1. **现有确定性基准。** 列出真实决策变量、块内状态方程、代价积分、首块执行与尾段近似，不再把当前程序描述成只有有限幅值候选。
2. **标准多阶段参照。** 相同模型、同一执行器、相同姿态任务和评价口径；信息节点共有一个动作。短稳健时域与真实分阶段信息揭示分开，不在下一个时刻假装知道整段真实未来。
3. **一个对象特定改动。** 明确“原式如何计算 -> 改哪一步 -> 预期改变哪类当前动作 -> 哪些假设下可以分析性质”。近期最贴近主线的候选仍是预测更新与慢执行之间的条件目标策略，但尚未证明它构成超越标准状态增广多阶段控制的机制。
4. **与改动对应的性质。** 如果主张执行可行，就说明所构造集合与真实可执行集的关系；如果主张时间误差鲁棒，就明确扰动集合、预测更新规则和闭环覆盖条件；如果主张计算简化，先说明计算为何值得优化。不能把所有性质都预先承诺。

通用参照形式可以写成

\[
\min_{\{r_n\}}\sum_n p_n\ell(z_n,r_n)+\sum_{n\in\mathcal L}p_n\ell_f(z_n),
\qquad z_{n^+}=F(z_n,r_n,\tau_{n^+}),
\]

其中每个 `n` 是一个可观测信息节点，`z`包括姿态、实际舱量与执行状态，共享信息的场景共用同一个 `r_n`。这是标准母体的项目表达，不是本项目原创。

只有同一模型、场景、约束和代价下，旧策略确实可行地包含在新策略集合中，并正确求解最优问题时，才能比较模型内最优值。不能用该集合包含关系直接证明真实长期闭环少泵或姿态更好。

### 6.3 原创性尚缺的那一步

“SDE/LSTM + 多阶段 + 时间误差 + 泵状态”是一份组件清单，不是原创机制。当前至少还缺：

> 标准母体对哪种明确的信息/执行结构采用了什么近似；这种近似为何对压载任务有实际后果；我们的新构造与已有状态增广、场景控制或约束收紧有何区别。

不能先假定标准多阶段没有后续补救能力，也不能先假定三舱六步算不动。不能把300/500 kg软件启停阈值当成实测硬件瓶颈，从而人为制造研究前提。

这不妨碍立即开始数学方法研究。它只是限定宣称：**目前已找到具体可借鉴的方法，还没有完成新控制算法，更没有证明收益。** 本轮未进行覆盖全部相关文献的查新，因此“尚未找到相同构造”也不能写成“文献中不存在”。

## 7. 收益和验证口径

北极星是相同姿态要求与设备能力下的实际压载负担，或相近负担下的姿态改善，保留二维权衡，不以某个调整过权重的综合分数替代。

\[
V_{\mathrm{pump}}=\sum_{i=1}^{3}\int_0^T |q_i(t)|\,dt.
\]

它不是三舱净水量，也不自动是电能或寿命。姿态至少保留RMS、峰值及预先定义的超阈持续时间。有限窗口交代末态，不把不同末态隐藏成节泵。

方法成型后的对照只需有明确作用分工：修正后的确定性基准、标准母体、母体加拟新增机制。若“加机制”和“完整方法”相同，不额外重复一组。改变预测模型与改变控制方法尽量分开，避免把均值更准误归为多阶段优势。

本轮不新增实验门槛，不展开10/20/30组，不调风险系数、场景数或控制权重。少量正确性检查用于实现阶段；独立数据上的收益、风险和泛化在方法明确后统一检验。负面结果也保留，不能从两个论文算例或本地几个窗口推断普遍提升。

## 9. 对用户随后提供的GPT Pro意见的补充判断

该意见对G逐时刻移位、分量关联、有限任务、可实现反馈，以及H的 `N_R=1`、`beta=1` 和两日期验证边界的判断与本轮全文核对一致。“组合方法也可以有价值”是必要修正：研究贡献不以是否发明全新定理或重写大量代码为唯一标准，但应有统一的问题、清楚接口及可独立验证的增量。

还需明确四点：

1. **鲁棒性不是节泵的同义词。** 收紧约束可能提前或额外泵送。论文目标应是可比姿态要求和误差覆盖下改善实际权衡；若只减少超限却增加泵量，必须如实作为权衡，不能合并成无条件提升。
2. **缩小不确定性不自动归因于控制算法。** 设共同事件偏移类为 `Omega_joint`，逐点独立移位类为 `Omega_ind`，前者通常是后者子集；更小集合自然可能使可行集变大、名义最优代价变低。这是集合关系，不是原创证明。新旧控制机制的比较尽量固定同一真实误差类别，并说明宽包络是计算近似还是物理假设。
3. **与执行一致不等于每个泵细节都要进入优化。** 先明确规划变量与实际质量增量的关系，以及可保证的执行偏差范围；可以研究保守但非空的可执行近似，不默认重建混合整数大模型。现有极端预演外包络本身不能用作可行性内保证，软件启停规则不能冒充硬件事实。
4. **有限时域结论要写到它实际覆盖的粒度。** 每10分钟端点满足约束不等于块内整个姿态轨迹满足；需要清楚区分离散采样点、现有5秒执行采样与连续时间结论。只证明固定预测、固定矩阵和给定执行误差界内的结论，可以是第一阶段产出，但不能包装成长期滚动LSTM闭环保证。

因此，最新意见可作为下一份数学方案的起点，而不是可直接执行的完整算法设计。建议把待回答问题压成一句：

> 在明确且有依据的预测误差类内，如何把风载时序误差传播为实际压载执行可支持的姿态/输入约束，并在同等任务与误差覆盖下改善现有控制器的姿态—泵量关系？

“改善现有控制器”目前是研究目标，不是已获结论。下一份草案优先写一套完整方程并标出原创候选的那一步，不先许诺无条件安全、递归可行、最优节泵或跨领域先进性。
