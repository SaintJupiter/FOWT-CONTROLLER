# OpenFAST名义状态动态释放检查

日期：2026-08-13

## 检查目的

本检查只判断VolturnUS-S公开输入中的零平台位姿能否直接作为P2低阶模型的外部已确认平衡点。它不是静平衡求解、阻尼标定或控制性能验证。

## 运行身份

- 求解器：OpenFAST `v4.1.2`，隔离环境位于`/tmp/fowt-openfast-4.1.2`。
- 基础输入：IEA 15 MW/VolturnUS-S `v1.1.16` OpenFAST输入的临时副本。
- 仿真时长：600 s，时间步长`0.025 s`。
- 禁用：风输入、气动、ServoDyn、波浪、叶片和塔架柔性自由度。
- 保留：整机质量、平台六自由度、HydroDyn势流水动力与静水恢复、MoorDyn系泊。
- 初始平台位姿：六个分量均为零。
- 可执行文件SHA-256：`94985b8cd9df32abbcfa8dd90f1e6a74520061f86421663d7795d17d9376865c`。

所有修改仅发生在`/tmp/fowt-openfast-equilibrium`，未修改仓库中的参考资料或正式模型参数。

相对公开输入，临时副本将`TMax`设为`600 s`，将`CompInflow`、`CompAero`和`CompServo`设为`0`，保留`CompSeaSt=1`、`CompHydro=1`和`CompMooring=3`；SeaState的`WaveMod`和`CurrMod`均为`0`；ElastoDyn只保留六个平台自由度，关闭叶片与塔架柔性自由度并将转速设为零；`OutFileFmt`设为文本输出。质量、惯量、HydroDyn水动力数据和MoorDyn系泊参数均未修改。

## 结果

| 量 | 全程范围 | 300--600 s均值 | 600 s时刻 |
| --- | ---: | ---: | ---: |
| 纵荡 / m | -0.152--0.984 | 0.442 | 0.800 |
| 垂荡 / m | -0.678--0.000 | -0.349 | -0.254 |
| 纵摇 / deg | -2.837--0.000 | -1.448 | -0.784 |

横荡、横摇和艏摇维持在数值零附近。纵荡、垂荡和纵摇在非零均值附近保持明显低频振荡，600 s内尚未衰减至静止。

## 可用结论与边界

这次动态释放说明，零位姿尚不能作为已经获得外部确认的六自由度静平衡初值。报告中的质量、排水量和系泊竖向预张力只能支持总体垂向载荷量级核对，不能单独确认六自由度力和力矩均在零位姿闭合。

当前结果不能用于认定上述均值或末时刻位姿就是静平衡位置，也不能据此判断官方模型设置错误。

## 数值松弛与重新释放

在相同临时工况中，按低阶质量和恢复刚度估算的各自由度临界阻尼量级加入对角线性耗散。六自由度对角项依次为`2.925e6`、`2.925e6`、`2.848e7`、`2.512e10`、`2.512e10`和`6.650e9`，单位按HydroDyn的平动与转动阻尼分块定义。该耗散只用于寻找候选初值，不表示物理阻尼。600 s后平台稳定在：

\[
x=0.4198\ \mathrm{m},\qquad
z=-0.3503\ \mathrm{m},\qquad
\theta=-1.452^\circ,
\]

其余三个位姿分量接近零。随后恢复原始HydroDyn阻尼设置，仅以上述位姿作为初值重新运行600 s。重新释放后300--600 s响应如下：

| 量 | 零位姿释放峰峰值 | 候选初值重新释放峰峰值 |
| --- | ---: | ---: |
| 纵荡 / m | 0.847 | 0.0133 |
| 垂荡 / m | 0.335 | 0.0002 |
| 纵摇 / deg | 1.857 | 0.0010 |

候选初值显著减小了重新释放振幅。因此，上述位姿可作为本次无风、无浪、刚性平台配置下的候选参考平衡，并用于定义低阶增量坐标与OpenFAST绝对输出之间的对照偏置。它不是完整柔性风机运行状态的通用平衡，也不用于标定正式阻尼。

## 候选参考初值工件

上述三个初值已固化为`configs/reference_platforms/volturnus_s_openfast_nominal_reference_state_v1.json`。该工件记录了公开模型压缩包的SHA-256、此次释放检查的运行边界和重新释放幅值；`scripts/validation/run_openfast_prescribed_wind_node.py`在使用前会核对压缩包哈希，并在输出中记录工件自身哈希。这样可避免将候选初值以脚本常量的形式脱离其模型身份使用。

该工件只为窄范围OpenFAST检查提供初值。转子载荷输入审计在将公开源文件中的轮毂位置和转子法向映射为广义载荷前，会以该候选纵摇角转入冻结平衡坐标。它不改变本节对其适用范围的限制，也不将数值松弛过程解释为物理阻尼或完整运行平衡求解。
