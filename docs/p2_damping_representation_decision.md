# P2低阶平台模型阻尼表示决定

日期：2026-08-13

## 目的

本文件只确定P2第一层低阶模型如何使用阻尼，不标定新的水动力参数，也不扩展OpenFAST中的辐射记忆或二次阻力实现。

## 已有证据

VolturnUS-S公开模型中的平台耗散不是一张固定线性阻尼矩阵。当前核对的HydroDyn输入采用辐射记忆模型，附加线性阻尼矩阵`AddBLin`为零，同时保留非零的二次阻力矩阵`AddBQuad`。因此，OpenFAST自由释放中的衰减由频率相关辐射作用和速度相关阻力共同形成。

候选参考平衡附近的`1 deg`纵摇自由释放得到约`28.50 s`的主周期。由相邻正负峰分别估算，前五个峰对的表观等效阻尼比约为`0.47%--0.48%`，末五个峰对约为`0.32%`，全段平均约为`0.39%--0.40%`。这一结果提示本工况的表观衰减随振幅发生变化，但单次耦合释放同时包含辐射记忆、二次阻力和模态耦合，不能据此确认具体阻尼机理，更不足以反演一张六自由度固定阻尼矩阵。公开报告中更大初始姿态下的自由衰减还包含不同结构自由度和气动条件，也不能直接移作当前刚性小扰动模型的阻尼参数。

完整峰值记录见`docs/openfast_pitch_decay_peaks_20260813.csv`。峰值从相对候选平衡`-1.452 deg`的纵摇增量中提取，同号相邻峰至少间隔`20 s`，峰值显著性阈值为`0.01 deg`，低于`0.05 deg`的峰不参与统计。对数衰减率和表观等效阻尼比分别按

\[
\delta_i=\ln\frac{A_i}{A_{i+1}},\qquad
\zeta_i=\frac{\delta_i}{\sqrt{4\pi^2+\delta_i^2}}
\]

计算。初始正峰作为第一个正向峰值纳入记录。

## 当前决定

1. 质量与恢复刚度的模态和自由响应核对继续采用零阻尼，避免阻尼假设掩盖矩阵装配问题。
2. `PlatformMatrices`保留显式传入常系数对称半正定阻尼矩阵的能力，但不提供默认经验值。该接口表示特定幅值和频率范围内的控制导向等效阻尼，不代表HydroDyn完整耗散机制。
3. 当前不新增辐射状态空间、卷积核、二次广义阻力或六自由度阻尼辨识模块，也不根据一次纵摇释放强行拟合完整阻尼矩阵。
4. 在形成新的控制性能结论前，应针对论文实际关注的纵摇、横摇幅值范围冻结一组有来源的局部等效参数，并检查合理变化范围内的结果敏感性。若节泵和姿态结论对该范围不敏感，第一层等效阻尼即可继续使用。
5. 只有当控制结论明显依赖姿态振幅，或固定等效阻尼无法复现关注范围内的衰减趋势时，才升级到速度相关阻力或辐射记忆表示。

## 能够与不能够支持的表述

当前可以表述为：低阶模型允许在声明适用范围后使用局部等效线性阻尼，质量与恢复矩阵组合已经完成无阻尼主模态核对。

当前不能表述为：已获得经过OpenFAST验证的六自由度物理阻尼矩阵，或低阶模型已经复现HydroDyn的频率相关和振幅相关耗散。

## 下一步边界

阻尼口径至此冻结，不再围绕单次自由释放继续调参。P2下一项工作回到三舱主动压载本身，只做变质量动量通量、总压载变化和自由液面效应的量级判断。量级判断完成前，不接入控制器，也不增加新的性能工况。
