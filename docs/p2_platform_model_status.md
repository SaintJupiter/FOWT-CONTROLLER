# P2低阶平台模型实施状态

更新时间：2026-08-13

## 已完成

- 在`src/fowt_platform`建立独立模块，不依赖旧版`archive/legacy_fowt_control/core_model.py`。
- 固定六自由度顺序为`[x, y, z, phi, theta, psi]`，速度定义为小角度增量广义坐标的时间导数。
- 分别保存质量、阻尼、静水恢复刚度和局部线性系泊刚度，并保证恢复项在动力学方程中只计算一次。
- 分别接收风、浪、压载和其他增量广义载荷。
- 实现既定参考平衡附近的静态增量偏移求解。该功能不替代重量、浮力和系泊预张力共同决定的基准静平衡求解。总恢复刚度无法约束全部受载方向时终止计算，不生成伪平衡结果。
- 实现气象来风方向到ENU去向风矢量、ENU到平台前向/左舷坐标及艏向与正艏摇之间的转换。
- 增加VolturnUS-S参考组件读取器，分别保留整机刚体质量、无限频附加质量、静水刚度和局部系泊刚度。组件不会自动拼接，候选装配必须显式选择整机表示并提供阻尼矩阵。
- 实现完整参考质量属性加三舱有符号质量增量的更新。三舱变化能够同步改变总质量、重心、参考点惯量和六自由度刚体质量矩阵，零增量严格保留公开源矩阵。
- 实现三舱质量增量对应的垂向重量和纵横摇力矩，并与左端质量矩阵更新分开计算，避免基准压载或压载作用重复计入。
- 增加三舱质量状态到平台物理量的薄边界，将三舱实际水量相对名义参考水量转换为有符号质量增量，并逐舱检查非负与容量上限。该边界不保存控制状态，也不参与候选动作选择。
- 将重量对纵摇和横摇的线性恢复项与WAMIT静水刚度分开保存。VolturnUS-S定义报告PDF第14页、2.1节表3前明确说明，WAMIT纵横摇项只包含水线面和浮心贡献，质量分项由OpenFAST另行计算。候选模型据此不再把两者混为同一参数。
- 保存公开报告中的名义垂向平衡证据。按报告给出的整机质量、排水体积和系泊竖向预张力计算，浮力减重量和系泊预张力后的残差约为`-0.95 kN`，仅占系泊竖向预张力约`0.016%`。这些取整数据只用于核对20 m吃水处的名义平衡，不替换OpenFAST运行矩阵。
- 解析方向、风速模长、载荷装配、增量静态偏移、非对角耦合、三舱质量映射、名义平衡审计及固定参数自由响应的针对性测试均已通过。仓库全量测试结果见本文件末尾的验证记录。
- 增加固定参数下的线性自由响应检查。该检查采用常系数矩阵的精确状态转移，不选择阻尼参数，也不接入外载、三舱变化或控制器。以3°纵摇初始扰动计算得到周期约`26.85 s`、频率约`0.03724 Hz`，与矩阵模态分析一致，无阻尼响应的相对能量漂移约为`9e-14`。这一结果只证明当前矩阵装配在频域和时域上的内部一致，不构成OpenFAST自由衰减或实际阻尼验证。
- 增加实际三舱水量到平台模型快照的单一装配接口。同一组经舱容检查的实际水量同时生成质量矩阵和压载增量重力载荷，避免两条路径使用不同舱状态。模型快照不是重新求解后的静平衡点，该接口也不保存舱状态、不推进水泵、不选择控制动作。

本地`v1.1.16`与官方`v1.1.18`的低阶平台输入已进行定向比较。两版的WAMIT静水矩阵、无限频附加质量和MoorDyn文件逐字节一致，ElastoDyn中的平台质量、重心和惯量以及HydroDyn中的排水体积也未变化。`v1.1.18`相关差异主要是OpenFAST 4.2字段和输出通道。因此，当前低阶装配继续使用本地具有完整来源哈希的`v1.1.16`，不为版本号单独迁移整套模型。

候选整机刚体质量、无限频附加质量、静水刚度、重量刚度和局部系泊刚度组成的无阻尼模型给出：纵荡/横荡约0.00778 Hz，艏摇约0.01208 Hz，纵摇/横摇约0.03723 Hz，垂荡约0.05047 Hz。VolturnUS-S定义报告相应结果为0.007、0.011、0.036和0.049 Hz。当前差异约为3%至11%，可支持继续开展低阶模型装配，但尚不能替代自由衰减和时域响应核对。

## 当前边界

当前实现只是P2的第一层数学骨架，尚不能用于新的控制性能结论。测试通过只说明接口、符号和当前方程内部一致，不代表平台参数或响应已经得到工程验证。

尚未接入的内容包括：

- 名义平衡的OpenFAST零载荷漂移或RAFT静力核对；
- 与OpenFAST自由衰减曲线的外部对照，以及幅值相关黏性阻尼的表示和标定；
- 三舱实际水量、进排水流量、舱容边界与上述质量增量接口的运行时连接；
- 总压载变化引起的吃水与静平衡更新；
- 变质量动量通量和自由液面效应的量级判断；
- 水泵执行、控制器和时间积分；
- 气动力、波浪载荷及系泊数据的正式模型；
- RAFT静平衡与频域检查，以及OpenFAST代表工况对照。

旧链路仍允许系泊文件缺失后自动采用线性替代。该行为只保留用于历史回归，新平台模块不继承这种静默回退。

## 下一层实施顺序

1. 用OpenFAST零载荷漂移或RAFT静力结果核对报告给出的名义平衡，并以公开自由衰减结果限定阻尼表示。当前不从报告图片反推一组固定阻尼矩阵。
2. 通过量级与敏感性计算决定动量通量、总压载变化和自由液面效应的处理方式。
3. 将三舱实际水量和水泵流量接入已经验证的质量与载荷映射，不在平台模块内引入控制决策。
4. 接入控制器，最后开展少量六小时整链路检查。

运行时连接复用现有控制链中的三舱实际水量、目标水量和容量边界，不在`fowt_platform`内另建一套舱状态。平台接口只接收“实际水量减参考水量”得到的有符号质量增量以及明确冻结的三舱坐标。逐舱非负和舱容上限由执行器状态层检查，平台质量函数只负责同一参考点下的质量、重心、惯量和载荷映射。

当前三舱分配矩阵的两列元素和均为零，未发生舱容裁剪时，候选目标只改变三舱水量分布，不改变目标总压载量。使用当前水泵配置对一个20 min执行阶段进行方向扫描时，最强候选动作产生的最大暂态净质量约为`39.4 t`，约占公开参考整机质量的`0.196%`，目标完成后的净误差约为`5 kg`。若将该暂态净质量作为纯垂向增量载荷施加于当前线性恢复模型，对应静态垂荡偏移约为`-0.086 m`。三台泵按当前名义最大流量同时运行时，质量流率上限为`768.75 kg/s`。这些结果只支持暂按缓慢变化质量参数安排建模顺序，不能证明吃水变化或动量通量可以忽略。动量通量还取决于进排水口面积、相对流速及方向，需在执行器几何和流动边界明确后另行核算。第一版运行连接仍应逐步记录实际总压载量，但不预先加入缺少参数依据的动量通量或自由液面模型。
