# P2低阶平台模型实施状态

更新时间：2026-08-21

## 已完成

- 在`src/fowt_platform`建立独立模块，不依赖旧版`archive/legacy_fowt_control/core_model.py`。
- 固定六自由度顺序为`[x, y, z, phi, theta, psi]`，速度定义为小角度增量广义坐标的时间导数。
- 分别保存质量、阻尼、静水恢复刚度和局部线性系泊刚度，并保证恢复项在动力学方程中只计算一次。
- 分别接收风、浪、压载和其他增量广义载荷。
- 实现既定参考平衡附近的静态增量偏移求解。该功能不替代重量、浮力和系泊预张力共同决定的基准静平衡求解。总恢复刚度无法约束全部受载方向时终止计算，不生成伪平衡结果。
- 实现气象来风方向到ENU去向风矢量、ENU到平台前向/左舷坐标及艏向与正艏摇之间的转换。
- 增加VolturnUS-S参考组件读取器，分别保留整机刚体质量、无限频附加质量、静水刚度和局部系泊刚度。组件不会自动拼接，候选装配必须显式选择整机表示并提供阻尼矩阵。
- 实现完整参考质量属性加三舱有符号质量增量的更新。三舱变化能够同步改变总质量、重心、参考点惯量和六自由度刚体质量矩阵，零增量严格保留公开源矩阵。
- 实现三舱质量增量对应的垂向重量和纵横摇力矩，并与左端质量矩阵更新分开计算，避免基准压载或压载作用重复计入。
- 增加三舱质量状态到平台物理量的薄边界，将三舱实际水量相对名义参考水量转换为有符号质量增量，并逐舱检查非负与容量上限。该边界不保存控制状态，也不参与候选动作选择。
- 将重量对纵摇和横摇的线性恢复项与WAMIT静水刚度分开保存。VolturnUS-S定义报告PDF第14页、2.1节表3前明确说明，WAMIT纵横摇项只包含水线面和浮心贡献，质量分项由OpenFAST另行计算。候选模型据此不再把两者混为同一参数。
- 保存公开报告中的名义垂向平衡证据。按报告给出的整机质量、排水体积和系泊竖向预张力计算，浮力减重量和系泊预张力后的残差约为`-0.95 kN`，仅占系泊竖向预张力约`0.016%`。这些取整数据只用于核对20 m吃水处的名义平衡，不替换OpenFAST运行矩阵。
- 解析方向、风速模长、载荷装配、增量静态偏移、非对角耦合、三舱质量映射、名义平衡审计及固定参数自由响应的针对性测试均已通过。仓库全量测试结果见本文件末尾的验证记录。
- 历史混合装配曾增加固定参数下的线性自由响应检查。该检查采用常系数矩阵的精确状态转移，不选择阻尼参数，也不接入外载、三舱变化或控制器。以3°纵摇初始扰动得到周期约`26.85 s`、频率约`0.03724 Hz`，与其矩阵模态分析一致，无阻尼响应的相对能量漂移约为`9e-14`。该内部一致性结论不延伸为当前对齐装配的外部验证。
- 增加实际三舱水量到平台模型快照的单一装配接口。同一组经舱容检查的实际水量同时生成质量矩阵和压载增量重力载荷，避免两条路径使用不同舱状态。模型快照不是重新求解后的静平衡点，该接口也不保存舱状态、不推进水泵、不选择控制动作。
- 使用OpenFAST 4.1.2和VolturnUS-S v1.1.16公开输入的临时副本完成零位姿动态释放、数值耗散松弛和重新释放检查。工况关闭风、波浪、气动、控制器及结构柔性自由度，保留整机质量、平台六自由度、HydroDyn和MoorDyn。零位姿释放后，纵荡、垂荡和纵摇围绕非零位置保持低频振荡；经临时耗散取得候选位姿并恢复原始阻尼重新释放后，三者后300 s峰峰值分别由`0.847 m`、`0.335 m`和`1.857 deg`降至`0.0133 m`、`0.0002 m`和`0.0010 deg`。候选位姿可作为该简化刚性配置下的参考平衡，但不是完整柔性风机运行状态的通用平衡。详细运行身份见`docs/openfast_nominal_state_release_audit_20260813.md`。
- 历史混合装配曾在候选参考平衡附近得到`1 deg`纵摇自由释放周期`26.88 s`，相对OpenFAST的`28.50 s`偏低约`5.7%`。静态恢复项对齐后，以同一无环境`1 deg`释放条件重新核对，低阶模型主周期为`27.65 s`，与OpenFAST相差`-2.98%`，响应方向一致。该结果只支持当前局部纵摇时间尺度有所改善，不分别证明质量矩阵和恢复矩阵正确，也不支持正式阻尼、完整六自由度响应或闭环控制已经通过外部验证。详见`docs/openfast_aligned_pitch_free_response_audit_20260821.md`。
- 冻结P2第一层阻尼表示边界。OpenFAST公开输入的耗散由辐射记忆和二次阻力共同形成，当前不将其简化结果冒充为完整六自由度物理阻尼。低阶模块只保留显式传入局部等效线性阻尼的能力，不设置默认经验值，也不新增辐射状态或二次阻力实现。详见`docs/p2_damping_representation_decision.md`。
- 完成三舱主动压载物理效应的第一轮量级划分。最大泵送能力在一个纵摇周期内对应的交换质量约占整机质量`0.109%`，支持将质量属性作为逐步缓慢更新参数。现有执行扫描中的暂态净质量仍可造成约`-0.086 m`静态垂荡偏移，因此总压载变化必须记录并进入质量和载荷更新。动量通量、自由液面和晃荡因缺少执行器或舱体几何暂不建模，也不视为已经证明可忽略。详见`docs/p2_active_ballast_effect_scope.md`。
- 完成水泵执行周期末状态到低阶平台层的数据交接检查。测试由现有三泵执行模型产生实际舱质量变化，再将同一组实际水量传入平台快照，核对总质量增量、压载重力、纵横摇力矩和瞬时状态导数使用同一份执行结果。连续两周期的双向调节进一步检查了进排水符号、总质量守恒和实际水量继承。该检查未引入新的桥接模块，也不依赖旧版`core_model.py`，但没有推进执行周期内的平台状态，不能视为连续时域动力学链路已经接通。
- 增加固定矩阵和固定外载下的最小单步推进。该方法用增广线性状态矩阵精确推进一个短时间步，不引入通用积分器、控制逻辑或新的平台状态所有者。零外载时，其结果必须与现有固定参数自由响应保持一致。实际运行时仍需将推进步长设置为远小于平台主运动周期，并在步末用执行器输出的实际舱水量更新下一步平台快照。
- 用两个`1 s`短步检查水泵和平台状态的因果更新顺序。在时刻`t_n`先由当时的实际舱水量生成平台快照，并在该快照和固定外载下推进至`t_{n+1}`；同一短步内，水泵从自身`t_n`状态推进并产生`t_{n+1}`实际水量；新水量只用于下一短步的平台快照。第二短步同时继承平台状态和水泵状态。该测试只冻结更新时间顺序，不构成完整运行器或性能验证。
- 增加独立薄运行脚本`scripts/validation/run_platform_ballast_short_chain.py`，复用上述顺序运行固定目标下的短时双向压载过程。30 s检查采用对称目标和相同泵速，因此该工况中的三舱总压载量保持不变，不能据此认为独立进排水过程天然满足总质量守恒。`1 s`与`0.5 s`结果的横摇和纵摇终值差分别为`1.31e-7 rad`和`2.27e-7 rad`，其余自由度响应量级很小，其中纵荡终值的绝对差为`1.81e-5 m`。这只是一个固定目标下的终点位姿差异检查，不构成步长收敛、变质量方程或控制性能验证。

本地`v1.1.16`与官方`v1.1.18`的低阶平台输入已进行定向比较。两版的WAMIT静水矩阵、无限频附加质量和MoorDyn文件逐字节一致，ElastoDyn中的平台质量、重心和惯量以及HydroDyn中的排水体积也未变化。`v1.1.18`相关差异主要是OpenFAST 4.2字段和输出通道。因此，当前低阶装配继续使用本地具有完整来源哈希的`v1.1.16`，不为版本号单独迁移整套模型。

静态恢复项对齐后的无阻尼装配给出：纵荡/横荡约`0.00776 Hz`，艏摇约`0.01208 Hz`，纵摇/横摇约`0.03617 Hz`，垂荡约`0.05038 Hz`。VolturnUS-S定义报告相应结果为`0.007`、`0.011`、`0.036`和`0.049 Hz`。该比较只用于确认低频时间尺度未出现数量级矛盾，不能替代自由衰减和时域响应核对。

## 当前边界

当前实现只是P2的第一层数学骨架，尚不能用于新的控制性能结论。测试通过只说明接口、符号和当前方程内部一致，不代表平台参数或响应已经得到工程验证。

尚未接入的内容包括：

- 候选参考平衡在完整柔性风机及其他运行状态下的适用性。当前只核对了无风、无浪的刚性平台配置；
- 纵摇、横摇实际关注幅值范围内的局部等效阻尼参数及敏感性核对；
- 总压载变化引起的吃水与静平衡更新；
- 变质量动量通量和自由液面效应在执行器与舱体几何明确后的进一步核算；
- 新低阶平台模型的连续时间推进及其与控制器的整链连接；
- 气动力、波浪载荷及系泊数据的正式模型；
- RAFT静平衡与频域检查，以及OpenFAST代表工况对照。

旧链路仍允许系泊文件缺失后自动采用线性替代。该行为只保留用于历史回归，新平台模块不继承这种静默回退。

## 下一层实施顺序

1. 保留当前无风、无浪刚性配置下的候选参考平衡，只将其作为低阶增量坐标与OpenFAST绝对输出的对照偏置。正式控制验证使用的局部等效阻尼另行声明适用幅值，不沿用本次临时耗散参数。
2. P2第一层平台物理在此冻结，不再增加动力学方程、经验效应或求解器选项。
3. 薄运行编排与短时终点差异检查已经完成，P2第一层实现停止扩展。
4. 后续另行规划控制器、风浪外载和少量整链检查，不在本阶段直接接入。

运行时连接复用现有控制链中的三舱实际水量、目标水量和容量边界，不在`fowt_platform`内另建一套舱状态。平台接口只接收“实际水量减参考水量”得到的有符号质量增量以及明确冻结的三舱坐标。逐舱非负和舱容上限由执行器状态层检查，平台质量函数只负责同一参考点下的质量、重心、惯量和载荷映射。

当前三舱分配矩阵的两列元素和均为零，未发生舱容裁剪时，候选目标只改变三舱水量分布，不改变目标总压载量。使用当前水泵配置对一个20 min执行阶段进行方向扫描时，最强候选动作产生的最大暂态净质量约为`39.4 t`，约占公开参考整机质量的`0.196%`，目标完成后的净误差约为`5 kg`。若将该暂态净质量作为纯垂向增量载荷施加于当前线性恢复模型，对应静态垂荡偏移约为`-0.086 m`。三台泵按当前名义最大流量同时运行时，质量流率上限为`768.75 kg/s`。这些结果只支持暂按缓慢变化质量参数安排建模顺序，不能证明吃水变化或动量通量可以忽略。动量通量还取决于进排水口面积、相对流速及方向，需在执行器几何和流动边界明确后另行核算。第一版运行连接仍应逐步记录实际总压载量，但不预先加入缺少参数依据的动量通量或自由液面模型。
