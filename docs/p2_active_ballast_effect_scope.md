# P2三舱主动压载物理效应范围

日期：2026-08-13

## 当前系统口径

三个压载舱分别与海水交换，不在舱间转移水量。平台模块逐舱接收实际水量相对名义参考水量的变化，并由同一组变化量更新总质量、重心、惯量和压载重力载荷。三舱目标在未发生舱容裁剪时总和不变，但独立水泵的执行过程仍可能产生暂态总压载变化，因此运行时不能预设平台总质量恒定。

## 已能量化的影响

当前单泵名义最大流量为`15 m3/min`，三泵绝对质量流率上限合计为`768.75 kg/s`。以OpenFAST纵摇主周期`28.50 s`计，一个周期内三泵能够交换的水量上限约为`21.9 t`，占公开参考整机质量约`0.109%`。对应的质量变化时间尺度明显长于平台纵摇周期，可在第一层模型中将质量、重心和惯量视作单个积分步内冻结、随水泵执行缓慢更新的参数。

现有20 min执行扫描中，最强候选动作的最大暂态净质量约为`39.4 t`，占整机质量约`0.196%`。将其作为垂向增量重量作用于当前线性恢复模型，对应静态垂荡偏移约为`-0.086 m`，约为20 m安装吃水的`0.43%`。这一量级不支持直接忽略总水量变化，第一版运行链必须逐步记录总压载质量，并将相应质量属性和垂向载荷传入平台模型。

## 暂不建模的影响

### 进排水动量通量

射流动量与进排水口面积、方向、相对流速和控制体边界有关。当前只有体积流量，没有进排水口几何，无法唯一计算作用力和力矩。因此第一层模型不加入经验射流载荷，也不声称该效应已经证明可以忽略。后续只有在执行器几何确定后，才按`rho Q^2/A`量级与压载重力矩、风载和平台惯性载荷比较。

### 自由液面效应

自由液面修正需要舱体截面、液位和液面二次矩。当前三舱只被定义为位于给定坐标的研究型点质量，没有足以计算自由液面修正的舱体几何。第一层模型继续采用点质量近似，并将自由液面列为后续几何明确后的敏感性项，不通过假定舱形补齐参数。

### 动态晃荡

当前没有舱内液体固有频率和阻尼信息，也没有证据表明其与平台关注频段接近。第一层模型不增加晃荡自由度。若后续舱体几何给出的晃荡频率接近纵摇或横摇频率，再升级模型。

## 实施决定

1. 保留现有点质量压载表示，并在每个执行步由实际三舱水量更新质量、重心、惯量和压载重力载荷。
2. 平台模型不自行保存水泵或目标状态，也不重新实现舱容约束。实际水量仍由执行器状态层唯一维护。
3. 总压载量变化必须进入运行日志，并作为后续吃水或参考平衡更新的输入证据。
4. 当前不增加动量通量、自由液面或晃荡代码。三者的升级条件分别是执行器几何、舱体几何和频率接近性证据出现。
5. 下一步只连接三舱实际水量与平台快照，验证同一执行步中的质量守恒、符号和状态传递，不开展控制性能优化。
