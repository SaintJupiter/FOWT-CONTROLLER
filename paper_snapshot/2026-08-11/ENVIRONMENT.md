# 运行环境说明

正式150组运行协议只记录了Python 3.12解释器路径，没有保存完整的环境锁文件。模型配置记录训练阶段使用PyTorch 2.8.0，但不能据此还原控制验证时全部软件包的精确版本。

建立快照时，本机环境为：

- Python 3.12.13
- NumPy 2.4.3
- pandas 3.0.2
- SciPy 1.17.1
- scikit-learn 1.8.0
- PyTorch 2.13.0.dev20260530
- joblib 1.5.3

该环境通过了仓库现有29项单元测试，但与2026年7月正式运行时的逐包环境不一定完全相同。后续科研版应建立锁定依赖文件，并在运行协议中保存Python版本、依赖版本、操作系统、代码提交、模型哈希和数据哈希。
