# 小论文投递版代码与证据快照

本目录冻结《基于短时风况预测的浮式风机主动压载调节算法》投递版本对应的代码身份、模型身份、工况清单和小型结果证据。快照用于后续程序清理、重写和结果追溯，不代表面向公开发布的完整复现数据包。

## 结果口径

- 控制配置：`rawenv_forecastgated_command_deadband_v1`
- 预测模型：`lstm_segmented_fino1_meteo_aux_v1`
- 工况数量：150组，每组6 h
- 名义仿真时长：900 h
- 不重叠风况时长：875 h
- 姿态反馈算法累计泵量：145871.94 m3
- 预测辅助算法累计泵量：116911.87 m3
- 累计泵量降低：19.85%
- 无未来预测对照相对姿态反馈算法降低：约0.90%

19.85%是完整预测辅助算法的联合结果，包含未来风况输入、候选动作规划、目标保持与释放、主动姿态刷新和水泵执行逻辑，不能解释为LSTM模型单独带来的收益。

## 已知限制

- 150组为条件筛选后的验证工况，不能代表全部连续风况中的平均收益。
- 150组名义时长为900 h，其中不重叠风况时长为875 h。
- 五组工况存在局部预测缺失，相关时段采用安全回退。剔除后总体结论不变。
- 当前目标释放发生在命令层，尚未与规划器内部目标完全同步。
- 当前六自由度模型属于简化等效模型，尚未经过OpenFAST等工具的系统交叉核对。
- 投稿稿件图2中的事件判断曲线混用了GRU来源，与正文及控制器使用的LSTM模型并非同一结果来源。该问题不影响150组控制验证的19.85%累计泵量结果，但图2后续应按LSTM指标重绘。
- 投稿稿件表2写有“水泵运行时间降低60.51%”。冻结原始结果按“实际泵送流量非零时间”复算得到61.85%，现有文件中尚未找到60.51%的独立计算依据，因此该指标不得在后续版本中直接沿用。
- 正式运行使用的系泊输入文件未被当前解析器识别，实际采用了程序内部的线性系泊回退。算法相对比较使用相同平台模型，但后续复现不得将本次运行表述为非线性系泊模型。
