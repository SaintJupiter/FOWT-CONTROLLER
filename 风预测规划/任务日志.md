## 一、长期参考：当前 LSTM 风预测系统知识

### 1. 当前系统整体流程

当前风预测模块的目标不是直接输出压载控制指令，而是为主动压载提前调节提供未来风况信息。整体逻辑为：

```text
历史风数据 -> 数据清洗和特征构造 -> 生成机器学习样本 -> LSTM 学习风变化规律 -> 预测未来风况 -> 输出风变事件概率 -> 支撑压载提前判断
```

当前输入是过去 120 分钟的 10 分钟风况序列，输出是未来 60 分钟的 10 分钟风况序列，以及未来是否出现明显风变事件。

### 2. 样本

一个样本就是模型训练时看到的一条训练材料。当前一个样本包括：

- 输入：过去 120 分钟风况；
- 时间间隔：10 分钟；
- 输入时间步：12 个；
- 每个时间步特征数：31 个；
- 输出：未来 60 分钟风况；
- 输出时间步：6 个。

也就是：

```text
过去 12 个风况点 -> 预测未来 6 个风况点
```

### 3. 特征

特征是给模型看的信息。当前特征包括：

- 风速；
- 风向的 sin/cos 表达；
- 风的 u/v 矢量分量；
- 过去 10 分钟风速变化；
- 过去 10 分钟风向变化；
- 过去 30/60/120 分钟平均风速；
- 过去 30/60/120 分钟风速波动；
- 小时和年周期信息。

这些特征的作用是让模型不仅看到当前风速风向，还能看到近期变化趋势和波动程度。

### 4. LSTM

LSTM 是一种处理时间序列的神经网络，适合学习：

```text
前一段时间如何变化 -> 后一段时间可能如何变化
```

在本项目中，LSTM 用于学习过去 120 分钟风速、风向和风矢量变化过程，并预测未来 60 分钟风况演化。

### 5. 参数量

参数量可以理解为模型内部可以学习的“旋钮”数量。当前第一版 residual LSTM 约有 30,225 个可训练参数，属于轻量模型，因此训练速度较快。它适合作为第一版基线，但还不是充分复杂的最终模型。

### 6. epoch

epoch 表示模型完整看一遍训练集。当前第一版训练为 8 个 epoch。由于第 8 个 epoch 仍是最优结果，后续可以尝试更长训练，例如 30-50 个 epoch，并配合 early stopping 防止过度训练。

### 7. batch 与 batch size

训练时不会一次读取全部样本，而是分批读取。batch size 是每次参与一次参数更新的样本数。当前 batch size 为 4096，训练集约 986,913 条样本，因此每个 epoch 约有 241 次参数更新。

较大的 batch size 会让训练更快、更稳定，但参数更新次数较少。后续可尝试 1024 或 2048，以增加模型学习细节的机会。

### 8. 损失函数

损失函数是模型的扣分规则。当前模型有两个任务，因此有两类损失：

- 数值预测损失：判断未来风矢量 u/v 预测得是否准确；
- 事件识别损失：判断未来是否出现风速突增、风向突变、矢量突变、高风速或压载关注事件。

当前模型使用双输出结构，同时训练这两个任务。

### 9. 双输出模型

双输出模型表示一个模型同时输出两类结果：

```text
输出 1：未来 60 分钟风矢量数值；
输出 2：未来 60 分钟风变事件概率。
```

这样做的原因是主动压载并不只关心未来风速的平均误差，更关心未来是否会出现需要提前关注的明显风变。

### 10. residual 回归

普通预测是直接预测未来风矢量。residual 回归则是预测未来风矢量相对当前风矢量的变化量：

```text
未来风矢量 = 当前风矢量 + 模型预测的变化量
```

短期风预测中，未来风况通常与当前风况接近，因此学习“变化量”比从零预测未来绝对值更合理，也更符合本研究关注的“风变化”。

当前表现最好的模型采用 residual 回归。

### 11. persistence 基线

persistence 是最简单的对照模型：

```text
假设未来风况等于当前风况
```

短时风预测中 persistence 往往很强，因为风况通常具有连续性。任何机器学习模型都应至少与 persistence 对比，确认是否真正学到了有用信息。

### 12. MAE

MAE 是平均绝对误差，用于评价数值预测误差。风速 MAE = 0.5862 m/s 表示模型平均风速预测误差约为 0.5862 m/s。MAE 越小越好。

### 13. recall

recall 是召回率，用于评价事件识别。它表示真实发生的风险事件中，有多少被模型识别出来。对压载提前判断来说，recall 很重要，因为漏报风险风况可能导致提前量不足。

### 14. false alarm rate

false alarm rate 是误报率，表示本来没有风险时，模型误判为有风险的比例。压载系统不能只追求高 recall，也需要控制误报，否则可能导致不必要的压载准备或调节。

### 15. F1

F1 是 precision 和 recall 的综合指标。它用于衡量事件识别是否在“找得多”和“别乱报”之间取得平衡。

### 16. hidden size

hidden size 是 LSTM 内部记忆空间大小。当前 hidden size 为 64。后续可尝试 128，以提高模型表达能力。

### 17. 层数

当前 LSTM 为 1 层。1 层模型训练快、结构简单，适合作为第一版基线。后续可尝试 2 层 LSTM 或 GRU，但不宜过早堆得太深。

### 18. early stopping

early stopping 是提前停止训练机制。它会在验证集效果连续多轮不提升时停止训练，并保存验证集表现最好的一版模型。作用是防止模型训练过久后死记硬背训练集。

### 19. 训练集、验证集、测试集

当前流程为：

- 训练集：用于模型学习参数；
- 验证集：用于选择最优 epoch 和事件阈值；
- 测试集：用于最终评价模型效果。

测试集不能用于调参，否则结果会虚高。

### 20. LightGBM / CatBoost

LightGBM 和 CatBoost 是传统机器学习中的强表格模型。若将过去 12 个时间点的特征摊平成一行，它们可以作为强基线。短期风预测中，表格模型有时会比简单 LSTM 更强，因此后续需要加入对比。

### 21. CNN-LSTM

CNN-LSTM 是在 LSTM 前加入卷积结构。CNN 用于提取短时间局部波动，例如最近 30-60 分钟内是否出现明显震荡，再由 LSTM 学习整体时间趋势。

### 22. TCN

TCN 是另一类时间序列模型，使用卷积处理时间序列。它训练速度快，对局部变化敏感，可作为 LSTM 之后的重要对比模型。

### 23. Transformer / TFT

Transformer 和 TFT 是更复杂的时间序列模型，适合多变量、长历史、多预测时域和需要解释变量重要性的场景。当前阶段不宜直接跳到 Transformer，应先把 LSTM、GRU、LightGBM/CatBoost、TCN 等基础模型对比清楚。

### 25. 后续可以加入的部分

后续可加入：

- 更长训练：让模型学得更充分；
- 更大 hidden size：提高表达能力；
- 2 层 LSTM 或 GRU：增强时间规律学习；
- 角度辅助损失：改善当前风向 MAE 略差的问题；
- LightGBM/CatBoost：建立强表格基线；
- CNN-LSTM/TCN：捕捉短时局部风变；
- 多阈值事件输出：区分观察、预警和真正压载动作；
- ECMWF/WRF/NWP 预报数据：让模型不仅看历史风，还参考未来天气预报；
- 姿态或载荷响应标签：进一步连接到“是否需要压载动作”。
